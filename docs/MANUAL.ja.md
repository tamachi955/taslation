# TASlation 詳細マニュアル

English: [MANUAL.md](MANUAL.md)

日常の操作は、アプリの「ヘルプ > 使い方」で読めます。ここには、設定やコマンドラインなどの詳しい説明をまとめています。

## 使い方

1. 本をビューアで開き、翻訳を始めたいページを表示します。
2. スタートメニューの「TASlation」から起動します。

3. 「ビューア」欄でビューアのウィンドウを選びます。TASlation はストアやビューアの名前を一切持っていないので、
   このパソコンで初めて使うビューアは自動では選ばれません（タイトルに「book」「電子書籍」「本棚」などの語があるウィンドウだけは自動で選びます）。
   一度選ぶと、次からは同じビューアのウィンドウが、TASlation の後に開いた場合も自動で選ばれます。ビューアらしいウィンドウが複数あるときは自動では選ばず、
   ステータス行でそう伝えるので、一覧から選んでください。ブラウザのウィンドウは「- Google Chrome」などを除いたタブのタイトルで判断し、
   「book」などの語や覚えたビューアの名前が長い語の一部にすぎないタイトルはビューアとみなしません。ブラウザのリーダーでは、
   タブやアドレスバー、リーダー自身の枠を除いたページの部分を自動で見つけ、そこだけを読みます。うまくいかないときは「ページ」メニューの「範囲設定...」で一度だけ、
   ページの周りに矩形をドラッグしてください（ウィンドウごとに記憶します）。設定した範囲は外枠として扱い、
   その中でもページの部分を探して読みます（見つけた部分は破線で表示します）。矩形は8つのハンドルで大きさを変え、内側のドラッグで移動、
   外側のドラッグで描き直せます。Enter で確定、Esc で取り消し、「範囲解除」で自動で探す状態に戻ります。
4. 「自動」は最初からオンで、ビューアでページをめくるたびに翻訳するか、キャッシュから呼び出します。
   翻訳者モードで編集するときなどは、チェックを外して追従を止めます。
   「翻訳 (F5)」は今のページを手動で処理します（キャッシュにあればそれを表示します。キャッシュを使わずに訳し直すのは、
   翻訳者モードの「訳し直す（キャッシュを使わない）」です）。OCR モデルの読み込み中などに押した場合は、処理できるようになってから実行します。

ウィンドウは、ビューアを常に見張ることなく、その今の表示を映します。TASlation からページをめくったときはその直後と1秒後に確かめるので、
先にぼやけた画像を描くビューア（ブラウザで読むビューアなど）でも鮮明な画像から読みます。
キャッシュにそろっているページは、新しい画像が届いた時点で、未訳の画像をはさまずにキャッシュから表示します。翻訳者モードでは、
画像が落ち着いてから（0.4秒間新しい画像が届かなければ）そのページをもう一度読み、キャッシュにない吹き出しを補います。
ビューアを直接操作しているときは0.7秒ごとに確かめ、どちらのウィンドウも前面にないときは確かめません（移動、タブの切り替え、
スクロールの後には一度確かめます）。どのウィンドウが前面かは Windows が知らせるので、ほかのウィンドウの中身は読みません。
`taslation.toml` で `follow = "poll"` とすると、常に0.7秒ごとに確かめます。

未訳のページは、見ている間に埋まっていきます。見つかった吹き出しを枠で示し（破線。読み取ると実線になり、文字でないとわかると消えます）、
ページの吹き出しを読む順に、前の台詞を文脈にして訳させます。訳ができた吹き出しから写植します。最後に、
シリーズ設定と違う綴りの名前を機械的にそろえるので、いくつかの吹き出しが変わることがあります。吹き出しに収まらない訳は、文字を小さくして組みます
（モデルに短くさせることはしません）。
処理中は右上のバッジに何をしていて何秒たったかを表示し、ステータスバーにも同じ内容が出ます。

### 画面1つで使う

2台目のモニターは要りません。「表示」メニューの「常に手前に表示」にチェックを入れて（または `--on-top` で起動して）、
TASlation をビューアの上に置きます。ビューアは下で描画を続け、取り込みもそのまま行えます。
Chrome は不透明なウィンドウに完全に覆われると描画をやめるので、TASlation のウィンドウは 99% の不透明度にしています。
それでもビューアが描かなくなったときは、最後の画像を残したまま、最大化を解除するかビューアが少し見えるようにずらすよう、
ページの上の帯で伝えます（画面の複製、つまり TASlation 自身の画像を表示することはしません）。帯の「TASlation をずらす」を押すと、
TASlation の最大化を解除し、ビューアが端に少し見えるように TASlation のウィンドウを狭めます（動かすのは TASlation のウィンドウだけです）。

ページは TASlation のウィンドウでめくるのが基本です。ビューアの操作は TASlation から行えます。TASlation があなたの押していないキーをビューアに送ることはありません。

* ページ上で押した矢印キー、Page Up/Down、Home、End、スペースはビューアに送られ、新しいページは表示され次第、
  翻訳されるかキャッシュから呼び出されます。
* ページ上のクリックは、ビューアの同じ位置に渡されます（クリックでページをめくるビューア、ツールバー、次ページの矢印、パネルを閉じるなど）。
  読者モード、読書モード、それに翻訳者モードで訳していないページを表示しているときに渡します。翻訳者モードで訳したページを
  表示しているあいだのクリックは TASlation のもので、文字領域の選択や編集に使います（ページはキーでめくれます）。

デスクトップのビューアには、キーをフォーカスを奪わずにウィンドウへ直接送ります。それを無視するビューアには実際にキーを押して
フォーカスを戻しますが、それはビューアの画像に3秒間（`page_turn_wait_ms`）まったく変化がなかった場合だけです。それでも2ページめくれたときは、
ステータス行にそう表示し、1ページ戻るキーを示します。どちらの渡し方でページがめくれたかはビューアごとに `profiles.json` に記録し、
次からは最初のキーからその渡し方を使います（3秒待つのは、そのビューアで最初の1回だけです）。ブラウザには、前面にないあいだに直接送ったキーが届きません
（Chrome と Edge で試して9回中0回）。そのためブラウザには毎回、一瞬前面に出してから実際にキーを押し、前面に出せなかったときは何も送らずに
「本をクリックしてそちらでページをめくってください」と伝えます。大きく読みたいときは TASlation の読書モード（F11）を使います。
ビューア自身の全画面表示は任意で、使うときはビューアの中でご自分で切り替えてください（次の「全画面のビューアの上に置く」）。

### 全画面のビューアの上に置く

任意です。ビューアをご自分で全画面にしたとき（TASlation が全画面にすることはありません）、ビューアが TASlation と同じモニターで
全画面（またはモニターいっぱい）なら、TASlation は Windows のスクリーン キーボードと同じように
振る舞います。常に一番手前に表示されますが、クリックしても前面（キー入力の行き先）にはなりません。前面はビューアのままなので、
ページ送りのキーはいつもどおりビューアに直接届き、TASlation は新しいページについてきます。ブラウザも描画を続けます。

* TASlation のボタン、チェックボックス、ページの帯などはクリックでそのまま使えます。
* F5（翻訳）は、ビューアが前面のあいだも TASlation が受け取ります（ブラウザ自身の再読み込みにはなりません）。読書モードの中では
  F11 と Esc も TASlation のもので、読書モードを終えます。
  それ以外の F11 と Esc、それにページ送りのキーはビューアのものです（ビューア自身の全画面の切り替えに使えます）。これらのキーを受け取るのはこのモードのあいだ、ビューアか TASlation が前面にあるときだけです。
* 文字を入力する欄（書名、翻訳先）をクリックしたとき、翻訳者モードでページを押したとき、ダイアログ（本の設定、シリーズシート、
  編集など）を開いたときは、そのあいだだけ TASlation が普通のウィンドウに戻ってキー入力を受け取ります。本をクリックするか
  ダイアログを閉じると元に戻ります。
* 本が別のモニターにあるときは何も変わりません。
* 「表示 > 全画面ビューアの上に表示」のチェックを外すとオフになり、次回の起動でもオフのままです（`taslation.toml` の
  `over_book = false` でも既定でオフにできます）。

### 読書モード

「読書モード」（ツールバーのボタン、または F11）は、原書を読む感覚で読むためのモードです。ビューアの上に黒い全画面を出し、
取り込み範囲を画面いっぱいに拡大して、訳したページだけを表示します。先に範囲をページにぴったり合わせておいてください。
ページ送りキーとクリックはビューアに渡り、自動が追従します（オフだった場合は読書中だけオンにし、その回の最初にそう表示します）。ステータスは画面下に数秒だけ表示します。
ウィンドウのあるモニターで開き、範囲もページの部分もわからないブラウザのウィンドウでは、F11 はまず「範囲設定...」か「このまま読む」かを尋ねます。
Esc か F11 で元のウィンドウに戻ります。マウスで戻るときは、ポインターを画面の上端まで動かすと右上に薄く「✕ 読書モードを終える（Esc）」が出るので、
それをクリックします（ポインターを下ろすと消えます。ほかの場所のクリックはこれまでどおりビューアに渡ります）。`taslation gui --reading` では、
ビューアを選んだ時点で読書モードで始まります。
書名がまだない本（タブのタイトルがビューアの名前だけのブラウザのビューアなど）を読書モードで訳したときは、その訳はどこにも保存されていません。
読書モードを抜けたときに一度だけ書名を尋ね、名前を付けるとそれ以降のページをその名前で保存します（表示中のページは F5 で保存できます）。

**吹き出しの拡大**: 読書モードと、通常のウィンドウの読者モードで、訳した吹き出しの上にポインターを少し置くと、その横に小さな窓を出し、
訳文を読みやすい大きさで、元の吹き出し（原文）の拡大と並べて表示します。読みにくい吹き出し（「小さい」の印が付いたもの、原文よりずっと長い訳、
画面上で読みやすい大きさ `readable_font_size` 未満に表示されているもの）は約0.5秒、ほかの吹き出しは約1.2秒で出るので、ページの上をポインターが
通り過ぎるだけでは出ません。訳文の大きさは `readable_font_size` の2倍（既定で22ピクセル）で、ページ上より小さくはしません。窓は吹き出しに重ねず、
ポインターが吹き出しを離れたとき、クリックしたとき（クリックはこれまでどおりビューアに渡ります）、ホイール、キー、Esc、ページが変わったときに消えます。
原文の拡大はメモリ上のページから切り出すもので、ディスクには書きません。窓はフォーカスを取らないので、全画面のビューアの上でもキーはビューアに届きます。
開くのはクリックではなくポインターを置いたときです（ページのクリックはビューアのものなので）。`taslation.toml` の `bubble_zoom = false` でオフにできます。

一度 1冊まるごと読んでおくと、どのページも即座に表示されるので快適です。読書モードでは未訳のページを1ページずつ翻訳し、
1冊まるごとの読み取りは読書モードを抜けるまで待ちます（バッチの実行中は読書モードを始めません）。全画面のウィンドウがビューアを覆うので、
ページはビューア自身が描いたものからしか取れません。ブラウザで読むビューアなどの Chromium 系のビューアは描きますが、
描かないビューアではページにそう表示されるので、Esc を押して通常のウィンドウで読んでください。

### 2つの読み方

**1ページずつ翻訳**（既定。「自動」と F5 の動作です）: ページを開いたときに、直前の数ページだけを文脈にして訳します。
ストアの利用規約に照らして最も無理のない読み方です。

**1冊まとめて先に翻訳**（任意）: 1冊まるごとの読み取りはダイアログで選んだときだけ行い、ダイアログには次の注意を表示します:
「ストアの利用規約は、あなたとストアの契約です。1冊まるごと読むときも TASlation はページをめくらず、あなたがめくったページだけを読み取ります。ただし、それでストアの規約上問題がないと決まるわけではありません。規約を確認し、そのことを承知のうえで使ってください。」（規約違反の結果は通常アカウントの停止で、犯罪ではありません。）

このモードで自動が本のキャッシュにないページに初めて出会うと、TASlation はまず翻訳できる状態か（Ollama が動いているか、モデルと OCR モデルが入っているか）を確かめます。足りないものがあれば、
何が足りずどう直すかをページの上の帯に表示し、直るまでは何も読み取らずに1ページずつ翻訳します（10秒ごとに確かめ直します）。

**ページの上の帯のボタン**。帯の各行には、TASlation が代わりに直せるものならそのボタンが付きます。

| 帯の表示 | ボタン | 押すと |
|---|---|---|
| 翻訳プログラム（Ollama）が動いていない | 翻訳プログラムを起動し直す | その場で Ollama を起動し、設定を確かめ直します |
| 翻訳先に要る翻訳モデルが入っていない | モデルをダウンロード | 大きさを示してダウンロードを尋ねます（前に「今はしない」と答えていても尋ねます） |
| ビューアらしいウィンドウが複数ある／ビューアが閉じられた | ビューアを選ぶ | 「ビューア」の一覧を開きます |
| ビューアのウィンドウが最小化されている | ビューアを表示 | ビューアを元の大きさに戻し、TASlation のすぐ後ろに置きます（キーは押さず、フォーカスも移しません） |
| ビューアが真っ黒なまま | ビューアを表示 | ビューアのウィンドウをほかのウィンドウの手前に出します。本をクリックして再読み込みしてください |
| TASlation がビューアを完全に覆っている | TASlation をずらす | TASlation のウィンドウだけを動かし、ビューアが少し見えるようにします |

1冊まるごと読む途中でビューアを待っているときも、ページの上の帯に同じボタンが付きます。
起動したときに翻訳がプロセッサー（CPU）で動くとわかれば（Ollama のログに書かれたグラフィックカードの有無で判断します）、
1ページの翻訳にかかるおおよその秒数を帯に一度だけ表示します。「閉じる」でそのセッションのあいだは消えます。

次に、小さなダイアログで書名を尋ねます（1ページずつ翻訳するモードでも、本の名前がまだなければ最初のページで同じように尋ねます）。
キャッシュとシリーズ設定はこの名前で保存されます。ブラウザで読むビューアには、どの本を開いてもタブのタイトルがビューアの名前だけのものがあり、
そうしたタイトルでは必ず尋ねます（ビューアやブラウザの名前を書名にすることはありません）。
タイトルのうちビューアの名前の部分は、このパソコンで覚えます。同じビューアで2冊目の本を選んだとき、または「書名」欄でタイトルからビューアの名前を除いた書名を入力したときに覚え、以後はその部分を書名に含めません。最初の1冊はタイトル全体が書名欄に入ることがあるので、そのときは書名を直してください。タブのタイトルがビューアの名前だけのブラウザのビューアでは最初に書名を尋ね、答えた書名から、そのタイトルが本の名前でないことを覚えます。
覚えた内容（ビューアとして選んだウィンドウのタイトルとプログラムのファイル名、タイトルのうちビューアの部分と本の部分）は、このパソコンの `~/.taslation/viewers.json` にだけ保存されます。キャッシュの書き出しにもログにも入らず、どこにも送られません。このファイルを削除しても、ビューアを一度選び直すだけで元に戻ります。
一度名前を付けた本は、どの取り込み範囲で読んでも翻訳済みのページから見分け、名前を入れておきます。複数の本が似ていれば欄の一覧に候補を出し、
見分けられなければ、同じビューアで前回付けた名前を入れておきます（「このビューアで前回読んだ本: ...」）。
ビューアのウィンドウの大きさを変えても、次に開いたとき本はページから見分けられます（見開きの2ページがそろって同じ本の別々のページに近ければ、その本と判断します）。古いキャッシュも当時のページの切り出し方で照合するので、そのまま使えます。

同じダイアログで、先に1冊まるごと読むかどうかも、上の注意とともに尋ねます。Enter は「1ページずつにする」を選びます（重いほうが勝手に始まらないように）。答えは本ごとに覚えます（状態フォルダの ui.json）。「1ページずつ」と答えた本はもう尋ねず、ステータス行にまるごと読む方法を表示します。「開始」と答えた本は次も尋ね、そのときは Enter が「開始」になります（実行はいつもあなたが決めます）。ダイアログを閉じると「今はしない」の意味になり、TASlation を閉じるまでその本は1ページずつ翻訳して、もう尋ねません（覚えはしません）。本の名前がまだないときに閉じた場合だけは、名前なしでは何も残せないので、次のページでもう一度尋ねます。読む場合は、ビューアでも TASlation のウィンドウのページキーでも、ご自分のペースでページをめくってください。TASlation はめくられたページを読み取るだけで、自分でページをめくることはありません。
最後まで読んだら帯の「読み終えた」を押すと、話全体を踏まえてまとめて翻訳します（中程度の GPU で190ページ約1時間。読み取りにかかる時間は、あなたが読む時間そのものです）。翻訳が終わるまで、訳は読めません。ページの上の帯に、読み取ったページ数と待ちのページ数、
1ページの読み取りにかかる時間、翻訳の進み具合（何行中何行か）とその棒、残り時間を「停止」ボタン付きで表示します。翻訳の進み具合は、タスクバーの TASlation のボタンにも緑の棒で出ます（読み取りが手を止めて待っている間は黄色）。読み取りのあいだは「自動」をオフにし（めくったページは読み取りが読みます。
最初の1回はステータス行にそう表示します）、終わると自動は再びオンになり、以後どのページも即座に表示されます。
翻訳が終わったとき、または問題で止まったときに TASlation が手前になければ、タスクバーの TASlation のボタンを点滅させて知らせます
（フォーカスは移さず、ウィンドウも前に出しません。ボタンは TASlation を開くまで点灯したままです。「停止」で止めたときは知らせません）。
設定 `flash_when_done = false` で点滅をやめ、`sound_when_done = true` で Windows の既定の音も鳴らせます（既定は点滅あり、音なし）。

翻訳が終わると、同じ人物の名前が訳文の中で複数の書き方になっていないかも確かめます（「竜司」が「Ryuji」と「Ryūji」に分かれている、など）。
見つかれば帯にその数と「名前を確認...」のボタンが出ます（「ツール」メニューの「複数の訳し方をされた名前...」からも開けます）。
名前ごとに書き方とその行数が並ぶので、残す書き方を選ぶか「その他:」に入力して「適用」を押すと、ほかの書き方の行をその書き方にそろえます。
「シリーズ設定に残す」にチェックがあれば（既定）、シリーズ設定の登場人物の表記にも入れ、以後の翻訳はその書き方を使います。
「適用」を押すまで何も変えません。変えるのは日本語にその名前がある行の、その名前の部分だけで、ほかの部分、要確認の印、訳注、位置はそのまま残ります。
「元に戻す」で行もシリーズ設定も元どおりにします（翻訳者モードでは行だけなら Ctrl+Z でも戻せます。そのあと「元に戻す」を押すとシリーズ設定も戻ります）。
見つけ方は決まった規則によるもので、モデルは使いません。日本語で「さん」「くん」「様」などの敬称が付いている名前（カタカナ2字以上、または漢字2～4字）だけを対象にし、
訳文に2通り以上の書き方があり、それぞれが別々の行にあって、同じ名前の書き方らしいときだけ出します（間違った提案をするより、見逃すほうを選んでいます）。
大文字のない言語（中国語、韓国語、タイ語など）の訳文では出ません。
日本語の行は TASlation を開いている間メモリに置くだけで、どこにも書きません。そのため対象は、このセッションで最後に1冊まるごと翻訳した本の、その実行で訳した行だけです。

どちらのモードも同じキャッシュを使います。

### 1冊まるごと読む（任意。規約を確認のうえで）

既定は1ページずつです。1冊まるごと読むには、ツールバーの「1冊まるごと読む...」を押します。1回に読むページ数の上限は設定ファイルの `batch_max_pages` です。
`--no-context` はコマンドラインでだけ使えます。バッチのダイアログにも、ストアの利用規約についての注意を「開始」の上に表示します。

1ページだけで訳すと、誰が話しているのか、前に何があり次に何が来るのかを知らないまま訳すことになります。「バッチ: 1冊まるごと読む...」は、
あなたがめくったページを読み取り、読み終えてから2つの段階でまとめて訳します。読み取りの間は、モデルへの要求を一切しません。

1. **読み取り**: 「開始」のときに表示中のページから、あなたがめくるたびに新しいページを取り込み、吹き出しを読みます（OCR）。TASlation はビューアにキーを送りません。
   ページはビューアでめくっても、TASlation のウィンドウでページキーを押しても（押した分だけビューアに渡します）、ページをクリックしてもかまいません。
   読み取りは1画面に約2秒かかりますが、速くめくっても大丈夫です。めくられたページはメモリの上で順番を待ちます（約24画面まで）。それ以上たまると、帯に少し待つよう表示され、空きができ次第、そのとき表示中のページを取り込みます。
   取り込む前にページがめくられたとき（表示されていた時間が短すぎたとき、またはぼやけた仮の絵のまま次へ進んだとき）は、ページの上の帯がすぐにそう伝え、
   ページの帯のその位置に点線の枠と「?」が出ます。ビューアでそのページに戻れば、ほかのページと同じように、本の順番どおりの位置で読み取ります
   （試験用のビューアでは、1秒に2ページめくっても取りこぼしはありませんでした）。
   前のページに戻っても二重には読まず、順番も変わりません。ページの画像はディスクには書かず、TASlation を開いている間だけメモリに置きます。
   使うのは、日本語を先に消しておくことと、翻訳中のページを映すことだけです。読み取った文字と位置も、
   この段階ではメモリの上だけです（200ページで約5 MB）。この段階ではまだどのページも読めません。
   ウィンドウにはいま表示中のページと、読み取った領域を映します。文字はまだ載せません。
   本の終わりを TASlation が判断することはありません。最後まで読んだら帯の「読み終えた」を押します（コマンドラインでは Enter）。待ちのページを読み終えると次の段階に進みます。
   しばらく手を止めてもかまいません。1時間ページがめくられないと画面が消えるのを止めなくなるだけで、続きから読み取ります。勝手に翻訳を始めることはありません。
2. **翻訳**: 「読み終えた」のあと、3〜5ページ分（`chunk_bubbles`、既定は30行）ずつ、シリーズ設定と話全体（前の台詞の訳文。
   Qwen ではさらに続く日本語）を手がかりに訳し、できた分から順にキャッシュに入れます。ここからはビューアに触れません。
   シリーズ設定と違う名前の綴りは機械的にそろえ、そのあと訳語と文字の大きさを確かめて要確認の印を付けます（モデルへの要求は増えません）。
   古い版の実行が下訳のまま残した行は、モデルに送らず、同じ段階でシリーズ設定と照らし合わせて訳として保存します。
   帯には「翻訳中: 全 n 行中 m 行」とその棒を表示し、モデルが1行訳すごとに進めます（PLaMo は1行ずつ、Qwen は返答が届くそばから）。
   ページの表示欄には、いま訳しているページを映します。モデルが1行訳すごとにその訳を吹き出しに載せ、まだ訳していない行は原文のまま枠で囲みます。
   訳がキャッシュに入ると、そのページはキャッシュのとおりの表示に置き換わります（それまでの訳は仮のもので、どこにも保存しません）。
   翻訳が次のページに進めば表示も進み、下のページ一覧ではそのページを枠で示します。一覧はどこまで進んだかを示すだけで、サムネイルをクリックしてもそのページは表示しません。
   読むときはビューアでそのページを開いてください。訳がその上に表示されます。ページの画像がメモリにもう無いときは、帯と一覧だけが進みます。
   翻訳が終わると（止めたときも、うまくいかなかったときも）、表示欄はすぐにビューアのページに戻ります。
   残り時間は、最初の1行ができてからの速さで計算するので、モデルを読み込む時間は入りません。8行以上、15秒以上たって速さが信頼できるまでは出しません。
   前回同じモデルで翻訳したときの速さが残っていれば（状態フォルダの ui.json、1行あたりの速さだけ）、そこから始めて、今回の速さに少しずつ置き換えます。
   1分を切ると「残り1分未満」、10分以上残っていれば終わる時刻（「13:40ごろ終了」）も出します。
   モデルが巻のノートを書いたり、訳を見直したりすることはありません（2026-11-06 に廃止）。モデルが知る本のことは、あなたが書くシリーズ設定だけです。
   `--no-context`（コマンドライン）はこの流れを使わず、あなたがめくるページを1ページずつ訳します。

**途中で止めたとき**。読み取ったページが3ページまでなら、読み取りの段階の「停止」はそのまま終わります。それより多く読み取っていると、
止める前に確認が出ます。「読み取りを続ける」（Esc と Enter はこちらを選びます）、「翻訳せずに停止」、「読んだページを翻訳」から選びます。
「読んだページを翻訳」は「読み終えた」と同じく待ちのページを読み終えてから、ここまでに読んだページを訳します。本を最後まで読んだことにはならないので、
あとで「1冊まるごと読む...」を実行すると、表示中のページから続けて読みます。Esc だけで処理が止まることはありません。処理の途中で Esc を押すと、
読み取ったページ数にかかわらず、この確認が出ます。
「翻訳せずに停止」では何も訳さず、帯に読み取ったページ数と「読んだページを翻訳」のボタンを表示します（本を読み終えていたときは「残りを翻訳」）。
読み取った内容はウィンドウを開いている間だけメモリに残るので、このボタンか、もう一度「1冊まるごと読む...」の実行で、続きから翻訳や読み取りができます。
訳していない読み取りが残っているとき、または読み取りの途中でウィンドウを閉じようとすると、閉じる前に確認が出ます（「TASlation を開いたままにする」が既定です）。
ウィンドウを閉じた場合やコマンドラインでは、読み取った分は失われ、キャッシュ済みでないページはもう一度めくって読み取ることになります（読み取りを始めたページに戻してから実行してください）。
翻訳の段階で「停止」すると（このときも先に確認が出ます。既定は「翻訳を続ける」です）、保存済みの訳はそのまま残り、進行中の要求の分だけが失われます。ウィンドウを開いたままなら、
もう一度実行すると読み取りなしで残りを翻訳します。ウィンドウを閉じた場合やコマンドラインでは、もう一度読み取りが要りますが、
訳済みのページは訳し直しません。止めてから自動などで訳したり直したりしたページは、続きの翻訳で上書きしません。読み取りの内容をディスクに書くことはありません。

モデルの応答は、崩れていても読める所まで読みます。使える訳がなかった行だけを、周りの行を文脈にして数行ずつ、それでも欠けていれば1行ずつ訊き直し、
それでも訳が得られない行は未翻訳のまま残し、ほかの行の訳はキャッシュに保存します。残った行は、そのページを読むときか次回の実行で、その行だけ訳します。句読点だけの行は、そのまま訳とします。

「停止」でいつでも止められます（進行中の要求の結果はキャッシュしません。確認と止めたあとの続け方は上のとおりです）。1ページの翻訳は Esc でも取り消せ、F5 でもう一度翻訳できます。
モデルが20秒何も返さないと、右上のバッジにそう表示します。要求が失敗したときは件数と理由をまとめに表示し、
Ollama が動いていないかモデルがない場合は再試行を繰り返しません。読み取りの間、ページをめくるのはあなたです。TASlation が自分でページをめくったり、
最後のページで勝手に止まったりすることはありません。最後まで読んだら「読み終えた」を押します。読み取りが終わればビューアはもう必要なく、画面が消えてもかまいません。
TASlation のウィンドウを開いている間は、画面も消えず、パソコンもスリープしません（画面が消えるとビューアが描き直しをやめるためです）。
ふたを閉じる、手動でスリープする、ロックするといった操作までは防げません。ウィンドウを閉じれば元に戻ります。

その後は、めくったページをページ指紋で見分け、保存した訳文をライブのページに重ねるので、即座に読めます。バッチに含まれなかったページは、
その場で訳してキャッシュに加えます。ウィンドウを閉じたあとで途中のバッチを続けるには、最初のページからもう一度実行するだけです。
キャッシュ済みのページは今の検出と照らし直し（文字領域に対応しなくなった吹き出しは捨てます）、キャッシュにない文字だけを訳すので、
検出が改良された後に実行し直せば、訳し直さずに古いキャッシュを整理できます。キャッシュの吹き出しは、
ライブのページの同じ位置に文字領域があるときだけ描きます。アプリとバッチは同じキャッシュを同時に開いていてもかまいません。
保存のたびにファイルの内容と統合するので、互いの訳文を上書きせず、バッチが追加した訳文はすぐにアプリに表示されます。

### ビューアの読み取り方

ビューアの画面は Windows.Graphics.Capture で取得します。ウィンドウがほかのウィンドウの裏にあっても読み取れ、取得した画像はメモリ上の最新の
1枚だけで、ディスクには保存しません。使えない環境では自動的に PrintWindow に切り替わります（どちらを使っているかは `taslation doctor` に
表示されます）。ディスプレイの電源が切れると描画が止まるので、TASlation のウィンドウが開いている間はディスプレイをつけたままにします。

ビューアを選んだとき、ビューアのウィンドウがモニターの作業領域より小さければ、ウィンドウの位置と大きさだけを変えて作業領域いっぱいに
一度だけ広げます。キーは押さず、フォーカスも移しません（最大化しているウィンドウはそのままです。そのあとあなたが小さくしたウィンドウもそのままです）。
ビューアの選択を変えたときや TASlation を閉じたときに、TASlation が広げた大きさのままなら元に戻します。TASlation が閉じずに終わったとき（異常終了など）は、
広げる前の位置と大きさを状態フォルダの `ui.json` に覚えておき、次に起動したときに、同じウィンドウが広げた大きさのままなら元に戻します。
1冊まるごと読む途中では、帯とボタンが見えるように、ビューアを動かしたり大きさを変えたりはしません。最小化されているビューアは「開始」で
表示し直します。ビューアのウィンドウは大きいほどよく読み取れます（「1冊まるごと読む...」の画面にもそう書かれています）。

1冊まるごと読むときの表示は、数をすべて「行」で数えます。前に翻訳済みのページは「翻訳済みの N 行」と表示し、帯の「読み取り済み」の数は、
ステータスバーとページの帯が示すページ数と同じです。キャッシュにあるページを表示するときは「翻訳中...」ではなく「ページを確認中...」と表示します。

隠れている間は描画を止めるビューアもあります。ビューアを選んだときと読書モードを始めたとき、ビューアがほかのウィンドウに完全に隠れていれば、
TASlation はキーを押さずに描き直しを頼み（ほかのウィンドウをどけたときに Windows が頼むのと同じものです）、隠れたままでも描くかどうかを確かめて、
ビューアごとに `profiles.json` に記録します。描かなかったビューアだけを、1ページずつ読むときにページごとに一瞬だけ手前に出し
（キー入力やフォーカスの移動はありません）、すぐ元の順序に戻します。一部でも見えているビューアは描画を続けるので、手前には出しません。
ブラウザは、不透明なウィンドウに完全に覆われたときだけ描画を止めるという公開されている決まりに従うので、確かめることはしません。ブラウザで読むビューアは、裏にあるとキーを受け取っても次のページを描かないので、TASlation のウィンドウで押したキーを渡すたびに一瞬だけ手前に出して実際にキーを押し、描き終わったら元の順序に戻します。
このとき一瞬フォーカスが移ります。1冊まるごと読むときも、あなたが押したキーは同じように渡しますが、それ以外にビューアを手前に出すことはありません。描画が止まったときは帯にそう表示するので、ウィンドウをずらしてください。

### ビューアが真っ暗なままのとき

ブラウザで読むビューアは、読み込み画面のまま止まったり、画面が黒いままになったりすることがあります。取り込む範囲が黒いままだと、TASlation は次のようにします。キーは一切押しません。

1. **待つ**: 読み込みが遅いだけかもしれないので、`black_wait_s`（既定 30 秒）待ちます。約 8 秒たつと「まだ読み込み中」と表示します。
   この間は 1 秒に 1 回ほど、新しいフレームが届いたかどうかをメモリ上で確かめるだけです（PrintWindow で取り込んでいるときは 2 秒に 1 回取り込みます）。
2. **知らせる**: それでも黒いままなら、本のウィンドウで再読み込みするよう一度だけ伝えます。本をクリックしてから、そのウィンドウの再読み込みキー
   （ブラウザなら F5）を押してください。TASlation のウィンドウの F5 は翻訳のキーなので、そこで押しても再読み込みにはなりません。

TASlation はそのまま待ち、ページが表示されれば、そのとき表示されているページから続けます。黒い画面を翻訳したりキャッシュしたりすることはありません。本当に真っ黒なページは読み込みが止まった画面と区別できないため、同じ扱いになります。

1冊まるごと読むときも同じです。帯に同じ案内を表示して待ち、ページが戻ると、そこから続けて読み取ります。読み取り済みのページに戻った場合は飛ばします。

### ページ送りのキー

TASlation のウィンドウでページキーを押すと、そのキーをビューアに1回渡します（1回押せば1回です）。TASlation が自分からキーを送ってページをめくることはありません。
漫画のビューアは右から左へ読むので ← キーが次のページ、画像ビューアや横書きの本は → キーが次のページです。
「ページ > ページ送りのキー...」で、選んだビューアごとに次のページと前のページのキーを設定できます。
TASlation のウィンドウでいつもの次・前のキー（「すべてのビューアに適用」の既定値、なければ `taslation.toml` のキー。初めは ← が次、→ が前）を
押すと、そのビューアに設定したキーとして渡します。たとえば Page Down で次のページに進むビューアなら、← を1回押すと Page Down を1回渡します
（ステータス行にもそう表示します）。ビューアに設定したキーそのものや、それ以外のキーは、押したとおりに渡します。キーの種類が変わるだけで、
回数は変わらず、あなたが押したときにだけ渡します。Backspace や文字のキーでページをめくるビューアにも、こうして TASlation から渡せます。
ビューアの全画面の上に置いているときは、キーがビューアに直接届くので、ビューアのキーを押してください。

* プリセット「右から左へ読む」（← 次、→ 前）と「左から右へ読む」（→ 次、← 前）を選ぶと、すべてのキーが一度に
  入ります。自分の組み合わせはキーの欄に入力して適用します（`profiles.json` に書いた名前付きのプリセットは `taslation keys` で使えます）。
* キーを試すときは、ダイアログを閉じてから TASlation のウィンドウでいつもの次・前のキーを押してください。ダイアログからビューアのキーを押すことはありません。
* 「このビューアに適用」はそのビューアだけ、「すべてのビューアに適用」は保存済みのすべてのビューアと、まだ設定のないビューアの
  既定値に書き込みます。

キーは状態フォルダの `profiles.json` にビューアごとに保存されます。画像ビューアのようにウィンドウのタイトルにファイル名が入る
ビューアは、タイトルの最後の「 - 」より後ろ（ビューアの名前）で 1 つの設定を共有します。タイトルがファイル名だけ（「000.jpg」など）か番号だけのブラウザ以外のウィンドウは、ウィンドウの
クラス名で 1 つの設定を共有するので、「000.jpg」を表示していたときに設定したキーと取り込み範囲は「001.jpg」でもそのまま使われます。どのキーを使うかは、ビューアの設定、
「すべてのビューアに適用」の既定値、`taslation.toml` の順に決まります。コマンドラインでは `taslation keys list` /
`show --viewer タイトル` / `apply left-to-right --viewer タイトル` / `set --all --next Right --prev Left` で同じことができます。

### 奥付と書名の変更

巻の終わり近くで、TASlation は奥付（書名、巻、著者、出版社、ISBN）を読み、キャッシュのヘッダーに保存して、
奥付による書名を本ごとに一度だけ提案します。「使う」か「今のまま」を選びます。

本の今の名前（最初に入力した名前や、ビューアの名前のまま保存した古いキャッシュ）でファイルがあるときは、「使う」で書名を変えます。
全言語の訳文とページに付けた情報を、新しい名前が別のシリーズに属するならシリーズ設定も、新しい名前に移し、
何をいくつ移したかをステータス行に表示します。

そのシリーズにすでにシリーズ設定がある場合（前の巻をフルタイトルに変えた場合など）は、この本のシリーズ設定をそこに統合します。
追加される内容はそのまま取り込みます。食い違う箇所（用語の表記、人物の一人称、文体ガイドの方針など）は、
何かを移す前に1件ずつシリーズの値とこの本の値を並べて表示するので、
「シリーズの方を残す」か「この本の方を採用」を選びます（まとめて選ぶこともできます）。「書名を変更」でその答えのとおりに書名を変え、
「キャンセル」なら書名はそのままで、奥付の書名は次回また提案します。この表は翻訳者の役割のときだけ出ます。読者の役割では尋ねず、どの行もシリーズの方を残して統合します。
答えることがなければすぐに統合し、追加した件数、この本の方を採用した件数、シリーズの方のままにした件数を表示します。

それ以外のものは上書きしません。新しい名前の訳文やページに付けた情報がすでにある場合は何も移さず、
邪魔になっているファイルを示します。

### ウィンドウの言語

初回の起動時に、どの国にいるかとウィンドウの言語を尋ね（「起動時の注意事項」参照）、`~/.taslation/notice.json` と
`~/.taslation/ui.json` に記憶します。言語は「言語」メニューでいつでも変えられ、
その中の「法的な注意事項...」（「ヘルプ」メニューにもあります）で国を変えられます。`--ui-language ja` や設定ファイルの
`ui_language` で指定することもできます。

組み込みの言語は17種類です: English、日本語、Español、Português (Brasil)、Français、Deutsch、
Italiano、Nederlands、Polski、Русский、Türkçe、Bahasa Indonesia、Tiếng Việt、简体中文、
繁體中文、한국어、ไทย。これはメニューとメッセージの言語で、訳文の言語ではありません。訳文は「翻訳先」欄の20言語のどれにでもできます。
「ヘルプ」メニューの「TASlation について」には、バージョン、ライセンス、通信相手がこのパソコンの Ollama だけであること、オフライン保護の状態、
キャッシュ・シリーズ設定・設定を保存するフォルダ、README と docs/THIRD_PARTY.md の場所があります。

### 翻訳者モード

ウィンドウには2つの役割があります。**読者** のときは、ページ上のキーとクリックはビューアに渡ります。ツールバーの「翻訳者」で
**翻訳者** に切り替えると、ツールバーの下に翻訳者モードの道具（読み順、このページを除外、訳し直す、この本の設定、シリーズ設定、レビュー、検索と置換、文字列の方向、元に戻す、やり直す。どれもここにだけあります）と、
マウス操作とキーの説明（「クリックで選択・ドラッグで移動・ハンドルで大きさ変更・丸いハンドルで回転（Shift で 15° ずつ）・ダブルクリックで編集・空いた所をドラッグで追加・Delete で削除・T で文字列の方向・Ctrl+Z で元に戻す・Ctrl+Y でやり直す・Tab で次の領域・Alt+矢印キーで 1px ずつ移動」。キーは「設定」の「ショートカット」で変えたものを表示し、キーを外した操作は省きます）が出て、
ページを編集できるようになります。

* **キーボード**: ページ上で Tab を押すと読む順に次の領域を、Shift+Tab で前の領域を選びます（最後の次は最初に戻ります。
  ステータスバーに何番目かが出ます）。Alt+矢印キーで選んだ領域を 1 ピクセル、Alt+Shift+矢印キーで 10 ピクセル動かし、
  キーを放して少したつと1回の移動として保存します（Ctrl+Z で1回で戻せます）。読者のときの Alt+矢印キーは、これまでどおり矢印キーとしてビューアに渡ります。
  書名や翻訳先の欄で Esc を押すと、ほかには何もせずにページにキー入力が戻ります（実行中の処理を止めることはありません）。
* **書式のコピーと貼り付け**: ワープロの書式のコピーと同じく、選んだ領域で Ctrl+Shift+C を押すとその書式（フォント、サイズ、太字・斜体、
  揃え、行間・字間、傾き、文字列の方向、文字の色と縁取り）を覚え、別の領域を選んで Ctrl+Shift+V を押すとその書式にします
  （Ctrl+Z で1回で戻せます）。種別（台詞・心の声・叫びなど）は翻訳のときにモデルに伝える前提情報なので、書式と一緒には写しません。
  「ページ」メニューの「この種別のすべての領域に書式を貼り付け...」は、コピーした書式を、選んだ領域と同じ種別の、この本のすべての領域に
  付けます（件数を示して確認します。種別は本の前提情報が持っているので、まだ表示していないページの領域にも付きます。
  種別が「指定なし」のときは、訳したページの領域が対象です）。どのページを表示していても、Ctrl+Z の1回で全体を元に戻せます。
  一括処理の実行中は使えません。Ctrl+C は選んだ領域そのもの（枠と書式）を覚え、同じレイアウトの別のページで Ctrl+V を押すと、
  同じ位置に領域を加えて読み取り・翻訳します（そこにすでに領域があるときや、ページの大きさが違うときは加えません）。
  すべてのキーは「ヘルプ」>「キー一覧...」（Shift+F1）で開く「使い方」の「キー」にまとめてあり（マウスの操作も載っています）、
  「使い方...」は F1 で開きます。ここに書いたキーはどれも最初のキーで、「設定」の「ショートカット」で変えられます。
  メニューの項目とボタンにも、そのときのキーを表示しています。

* **領域**: 文字領域をすべて枠で示します（緑: 訳済み、オレンジ: 未訳、青: 自分で指定した領域、赤で「?」: 訳済みだが要確認）。話者と、
  文が続く場合の「...」も表示します。枠・選択枠・ハンドル・回転ハンドル・ドラッグ中の矩形は、色の線の下に暗い線を重ねた2色の線で描くので、
  白いページでも黒いページでも見えます。話者などのラベルは、空きがあれば隣の領域にかからない位置（上、下、左右の順）に置きます。
  検出されなかった文字を矩形で囲むと、読み取って翻訳し、
  ページに加えます（以後の読み取りやバッチでも使われます）。領域はオフィスソフトの図形のように、クリックで選択、ドラッグで移動、
  ハンドルで大きさを変えられ、新しい枠がより広い範囲を含むときだけ読み直します。選択した枠の上辺の中央から伸びた丸いハンドルを
  ドラッグすると、Word の図形と同じように枠の中心のまわりで回転し、離したところで写植し直します（Shift を押しながらだと 15° ずつ、
  押さなければ 0° の前後 3° はまっすぐに吸着します。範囲は左右とも 89° まで、Esc でドラッグを取り消し、Ctrl+Z で元に戻せます）。
  回転は編集画面の「傾き」と同じ設定で、傾けた枠はその向きで表示され、ハンドルも傾いた枠の上に付きます。
  傾いた枠のハンドルは、ページの上でそのハンドルが向いている側に、元の（傾いていない）枠を広げたり縮めたりします。Delete で削除し、
  削除した領域はそのページで「文字ではない」と記憶されるので、誤検出が戻ってくることはありません。
* **複数の領域の選択**: オフィスソフトの図形と同じく、Shift を押しながらクリックすると領域を選択に加え、もう一度クリックすると外します。
  Shift を押しながらドラッグすると点線の四角が出て、その中にすっぽり入った領域をすべて選択に加えます（選んだ領域のハンドルや
  丸いハンドルの上で Shift を押したときは、これまでどおり大きさの変更と 15° ずつの回転です。Shift なしで空いた所をドラッグすると、
  これまでどおり領域を加えます）。複数を選ぶと、それぞれの枠をハンドルなしで描きます。どれかをドラッグするか Alt+矢印キーを押すと
  まとめて動き（どれかがページの端に着いたところで全体が止まります）、Delete でまとめて削除し、T でまとめて文字列の方向を切り替え、
  Ctrl+Shift+V でまとめて書式を貼り付けます。「ページ」メニューの「種別を設定...」と「文字サイズを設定...」は、選んだ領域
  （1つでも複数でも）の種別と文字サイズ（「自動」で収まる大きさに戻ります）を決めます。どれも1回の変更として Ctrl+Z で元に戻せ、
  戻すと対象の領域がまた全部選ばれた状態になります。選んだ領域の1つを動かさずにクリックするとその領域だけを、Tab で次の領域1つを選び、
  Esc で選択を解除します。
* **全ページで無視する範囲**: 透かし、ノンブル、毎ページの帯のように、どのページでも同じ場所に出て訳したくないものは、その領域を選んで
  「ページ」メニューの「この本の全ページでこの範囲を無視」を選ぶと、その場所（領域の枠を少し広げた範囲）を本の全ページで無視します。
  ほかのページで削除したのと同じ場所の領域を削除したときも、削除を保存したあとに同じことを尋ねます（「このページだけ」と答えた場所は、
  ウィンドウを閉じるまで二度と尋ねません。自分で追加した領域を削除したときは尋ねません）。範囲にほぼ（面積の 70% 以上）収まる検出は、
  表示中のページでも本全体の処理でも見つからなかったものとして扱い、描かれたまま残します。自分で追加した領域は範囲の中でも残ります。
  見開きのページで決めた範囲はその側（右か左）のページと1ページずつ表示したページに、1ページずつ表示したページで決めた範囲はすべての
  ページに当てはまり、形の大きく違うページ（見開きを1枚の画像にしたものなど）には当てはまりません。追加はどのページを表示していても
  Ctrl+Z の1回で元に戻せます。範囲の中の訳文はキャッシュに残るので、元に戻すとそのまま戻ります。保存するのは範囲の4つの数値、
  見開きの側、ページの縦横比だけです。一括処理の実行中は追加できません。
* **領域の編集**: ダブルクリック（または選択中に Enter）で開きます。書式の欄は、その領域に書式の指定がなければ「書式」のボタンの中に畳まれています。**話者**（シリーズ設定の名前から選べます）、**種別**（台詞、
  心の声、叫び、ナレーション、効果音、手書き、消去のみ）、**文が次の吹き出しに続く** かどうか、**翻訳者への注記**（言葉遊び、誰に向けた台詞か）、
  訳文を変えられます。Enter で改行し（写植でもその改行を守ります）、Ctrl+Enter で保存します。
  種別を「消去のみ」にすると、その領域の元の文字を消すだけで、そこには何も写植しません（選ぶとすぐ後ろのページに消した姿が出ます）。
  翻訳には送らず（本全体の処理でも同じです）、要確認にも未訳にも数えません。前の訳文はキャッシュに残るので、種別を戻せばまた写植されます。
  変更は Ctrl+Z で元に戻せます。
  編集画面の上には、取り込んだ画面から切り出したその領域の元の姿が出ます（メモリ上だけの画像で、どこにも保存しません）。
  キャッシュから表示したページは日本語を持たないので（キャッシュは訳文しか保存しません）、「日本語を読み取る」でその場で読み直すと、
  「読み取り結果:」が出て「もう一度訳す」も使えます（読み取っていないまま「もう一度訳す」を押すと、先に読み取ります）。
  「前へ (Alt+↑)」「次へ (Alt+↓)」で、読む順にひとつ前・後の領域の編集に移ります（キーは「ショートカット」で変えられます）。変えた内容があれば、移る前に「保存」と同じく保存し
  （Ctrl+Z で1回の変更として元に戻せます）、何も変えていなければ何も書き込みません。
  何かを変えたまま Esc かウィンドウの閉じるボタンで閉じようとすると、変更を破棄してよいか尋ねます（「編集を続ける」が既定です）。
  「キャンセル」のボタンは尋ねずに閉じます。
* **書式バー**: 訳文の上の書式バーは、ワープロのテキストボックスのように使えます。
  「太字」「斜体」（「自動」でシリーズ設定の種別ごとの指定に戻ります）、**フォント**（このパソコンに入っているフォント。
  そのフォントがないパソコンでは自動選択のフォントを使います。一覧の先頭には、横の ☆ でスターを付けたフォント、次に最近使ったフォント
  （最後の10個）が並びます。★ をもう一度押すとスターを外します。Tab で移って Space でも押せます。覚えるのはフォントのファミリー名だけで、
  このパソコンの ui.json に保存します）、**サイズ**（「自動」は収まる最大の大きさ。固定したサイズは縮めず、
  収まらない文字は吹き出しの縁で切れ、そう表示します）、「文字幅を詰めて収める」（14ポイント未満では自動）、
  左揃え・中央揃え・右揃えと上揃え・上下中央・下揃え、**行間**、**字間**、**傾き**（反時計回りの角度。「自動」は元の文字の傾きのまま）、**文字列の方向**（Word のテキストボックスと同じく、自動・横書き・すべての文字列を 90° 回転（上から下へ読む、英語の本の背表紙の向き）・すべての文字列を 270° 回転（下から上へ読む）・縦書き（文字を縦に積み、右から左へ列を並べます。長音「ー」やダッシュ、「…」、かっこは縦書き用の形にし、小さいかなと句読点は縦書きの位置に置き、ラテン文字は1字ずつ立てて積みます。縦中横やルビには対応していません）。傾きと組み合わせると、方向を決めた文字を枠ごと傾けます）、**文字の色**と**縁取りの色**（自動・黒・白・カスタム...。カスタムでは Windows の色の設定画面で好きな色を選び、横の色見本をクリックすると選び直せます。ネットには何も問い合わせません）、**縁取り**（自動・縁取りあり・縁取りなし）、「書式をリセット」があります。色と縁取りの「自動」は、シリーズ設定がその種別に決めた色と縁取りに従い、決めていなければ、文字は背景に合わせて黒か白、縁取りは絵やトーンの上だけ、縁取りの色は文字と反対の色になります。色と縁取りは文字の大きさや改行を変えません。「書式のコピー」（Ctrl+Shift+C）でバーの書式を覚え、「書式の貼り付け」（Ctrl+Shift+V）で別の領域の編集画面のバーに入れられます（「保存」で確定します）。翻訳者モードでは、選択した領域で T を押すか「文字列の方向 (T)」ボタンを押すと、自動 → 90° 回転 → 270° 回転 → 縦書き → 自動の順に切り替わります（Ctrl+Z で元に戻せます）。変更すると、
  少しして裏のページで写植し直します。書式は本のページ情報と一緒に保存されます。
* **シリーズ設定への反映**: シリーズ設定が別の表記にしている名前や用語を自分の編集で置き換えると、それをシリーズ設定の表記にするかを尋ね、
  すでに訳したページでも置き換えます（訳文の置き換えは1回の変更として Ctrl+Z で元に戻せます。シリーズ設定の表記は戻りません）。
* 「読み順」は、自動で決めた順番が違うとき、読む順に領域をクリックして指定します（分かれた文や、誰が誰に答えているかはこの順番で決まります）。
  翻訳者モードでは、各領域の読み順の番号を枠の横の小さな丸い印に表示します（隣の領域やラベルにかからない位置に置きます。
  「表示」メニューの「読み順の番号」でオン・オフでき、次の起動にも引き継ぎます。「読み順」で順番をクリックしている間は、
  ラベルに番号が出るので印は出しません）。1つの領域だけ順番を直すときは、その領域を選んで「ページ」メニューの
  「読み順の位置を指定...」で何番目にするかを入れます（複数を選んでいれば、その並びのままその位置に置きます。ほかの領域の順番は
  変わりません。Ctrl+Z で元に戻せます）。
  「このページを除外」は、広告やビューア自身のパネルなど訳すもののないページに印を付け、
  「訳し直す（キャッシュを使わない）」は今の前提情報でページを訳し直します。
* 「レビュー...」は、そのページで見ておくべき領域（要確認の印、未訳、読者への訳注あり）を一覧にします。
  編集画面の「もう一度訳す」は前の台詞を文脈にしてその吹き出しを訳し直させます（別案を並べる機能はありません）。
  辞書にない語を含む訳文も要確認にするには、`pyspellchecker` を入れます（`pip install pyspellchecker`。
  MIT ライセンスで、英語・スペイン語・フランス語・ポルトガル語・ドイツ語・イタリア語・ロシア語・オランダ語の単語リストをディスクに持ちます。
  シリーズ設定の名前と表記は対象外です）。設定のスペルチェック（`spellcheck`、既定でオン）が有効なのにこのパッケージが入っていないときは、
  編集画面を最初に開いたときに一度だけそう伝えます（ネットからは何も取得しません）。
* 「元に戻す」（Ctrl+Z）は表示中のページの変更（訳文や注記の編集、領域の移動・大きさの変更・追加・削除（複数の領域をまとめて
  した変更も1回）、保存した書式、種別と文字サイズの設定、
  「このページを除外」、読み順の設定、「訳し直す」）を新しい順に取り消し、
  「やり直す」（Ctrl+Y）でまた適用します。ほかのページでの変更は、そのページを再び表示したときに取り消せます。
  「訳し直す」を取り消すと、そのページの前の訳文が戻ります。何も訳さずに終わった訳し直し（停止など）は取り消す対象になりません。
* 「検索と置換...」（翻訳者モードのボタン）は、今の本の、今の言語の訳文全体を検索して置き換えます。
  たとえば人物名の誤りを1冊分まとめて直すときに使います。ウィンドウを開いたまま本を読み進められ、入力するたびに、一致した箇所が
  ページ番号と前後の文字とともに一覧に出ます（`«` と `»` の間が一致した部分です。ページ番号は本のノンブルではなく、
  キャッシュに入った順の番号です）。「大文字と小文字を区別」と「単語全体」で絞り込めます。「単語全体」は、日本語、中国語、韓国語、
  タイ語のように単語の間に空白を置かない文字の隣では区切りを見ません。
  「置換」のボタンを押すまで何も書き込みません。「選択した行を置換」は一覧で選んだ箇所だけを（Ctrl キーと Shift キーで複数選べます）、
  「すべて置換」は一致したすべてを置き換えます（一覧に出るのは最初の500件までですが、件数と「すべて置換」は全件が対象です）。
  表示中のページはすぐに写植し直し、ほかのページは次に表示したときに新しい訳文で出ます。

  変わるのは訳文だけです。要確認の印、読者への訳注、下訳の印、未完了のページの印、吹き出しの位置はそのまま残ります。
  1行ずつ見て直したわけではないので、領域の編集と違って、要確認の印を消しません。訳文が空になってしまう吹き出しは置き換えず、そう表示します。
  置換は全体で1回の変更で、それが本の最新の変更である間は、どのページを表示していても Ctrl+Z で全ページまとめて元に戻せ、
  Ctrl+Y でまた適用できます（検索と置換のウィンドウの中でも同じです）。そのあとにほかのページを編集すると、先にその編集を取り消す必要があります。
  訳し直されて内容が変わった吹き出しは、元に戻す対象から外れます。

  シリーズ設定は自動では変わりません。「すべて置換」で置き換えた語句がシリーズ設定の表記だったときだけ、領域の編集のときと同じように、
  新しい表記にするかを1回だけ尋ねます。一部の行だけを置き換えたときは尋ねません。元に戻してもシリーズ設定の変更は戻りません。
  バッチの途中やページの処理中は置き換えられません。終わってからもう一度押してください。
* 「この本の設定...」は、この本に合う検出と OCR の値（しきい値、文字ブロックの検出、効果音）と、この本の写植の大きさ
  （「写植の大きさ」と「最大の大きさ」。「設定のまま」と空欄は「ツール > 設定...」の値）を、自分の設定を変えずに、
  本の前提情報と一緒に保存します。「この本に適用」を押すと、表示中のページをキャッシュから組み直します（訳し直しはしません）。
  「すべて消去」は、消える設定の数を示して確認してから消し（既定のボタンは「残す」です）、
  ウィンドウを開いたままにします。その間は「元に戻す」で消した設定を戻せます。その下には、この本の全ページで無視する範囲が
  当てはまるページ（全ページ・右側のページ・左側のページ）と位置（ページの幅と高さに対する %）で並び、「範囲を削除」（一覧で Delete キーでも可）で
  選んだ範囲をすぐに外せます（そこでも再び文字を探します）。「元に戻す」は、このウィンドウで最後にしたこと（すべて消去か範囲の削除）を取り消します。
* 「シリーズ設定...」は、シリーズごとに、用語（用語とその訳語・表記）、登場人物（性別、年齢、一人称、話し方、役割、ほかの人物の呼び方）、
  文体ガイド（敬称の方針、トーン、ハウスルール、シリーズが提案する描画フォント、種別ごとの書体と文字の色・縁取り・縁取りの色）を保存します。種別ごとの色と縁取りは、その種別の領域の「自動」になり、編集画面で領域ごとに決めた色と縁取りがそれより優先されます。書体以外はすべて、
  翻訳の前にモデルに伝えます。入れるのは事実だけで、本の台詞は入れません。描画フォントは Comic
  Neue のようなファミリー名で指定し（`taslation glossary font` でも設定できます。描画フォントと種別ごとの書体の欄は一覧からも選べ、
  編集画面と同じく、スターを付けたフォントと最近使ったフォントが先頭に並び、横の ☆ でスターを付けられます）、
  そのフォントがこのパソコンに入っていれば字形がある限り使い、入っていなければそう表示して、自動選択のフォントを使います。
  用語や登場人物の「選択項目を削除」は、削除するものの数と名前を示して確認します（既定のボタンは「残す」です）。
  下の「元に戻す」は、このウィンドウで最後に加えた変更（追加・更新・削除・文体ガイドの保存）を1回分取り消します。
  用語や登場人物の訳語・表記を変えると（「元に戻す」で戻したときも）、古い表記を使っている翻訳済みの行がいくつあるかを示し、
  新しい表記にするかを尋ねます。「{n} 行に適用」で、キャッシュのその本・その言語の訳文を単語単位で置き換えます（「Miyu」を変えても
  「Miyuki」は変わりません。表示中のページはすぐに写植し直します）。置き換えは全体で1回の変更で、検索と置換と同じく Ctrl+Z で元に戻せます。
  ページを処理中なら終わってから尋ね、本全体の実行中は置き換えずに、そう表示します（終わったあとに「検索と置換」で直せます）。

話者、種別、続きの印、注記はそれぞれの吹き出しに添え、シリーズ設定は吹き出しの前に置いてモデルに渡します。保存先は
`~/.taslation/annotations/<book>.json` と
`~/.taslation/glossary/<series>.json`（同じファイル名になる名前は `<name>-<hash>.json`）で、
中身は位置、事実、方針だけです。本文も訳文も入りません。

前提情報の効果は、本がなくても
`python tools/premises_eval.py` で測れます（テスト用の台詞をシリーズ設定ありとなしで訳し、名前、代名詞、敬称、
分かれた文、話し方を採点します）。既定のモデルでは、シリーズ設定で通過率が58%から90%に上がりました。実際の巻を、
本と照らして事実を確かめたシリーズ設定で訳し直すと、人物名の誤りは208件から0件になり、文脈付きのブラインド評価では、
変わった吹き出しの51%で新しい訳が、36%で古い訳が好まれました（`docs/OFFLINE_VERIFICATION.md`）。
事実は先に確かめてください。モデル自身の推測で書いたシリーズ設定は、ないのと変わりませんでした。

### ページ指紋

ページ指紋は、ページの内容部分の320ビットの知覚ハッシュ（縮小したページの 16x16 の勾配ハッシュと 8x8 の明るさのハッシュ）で、
ファイルのハッシュではありません。同じページを別の大きさやズームで取り込んでもほぼ同じビットになり、違いが36ビット以内なら「同じページ」とみなします。
指紋からページを復元することはできません。似たページ（白紙、繰り返し出る広告）は、縦横比と順序の中の位置で区別します。

### ブラウザで読む場合: 本のタブを専用のウィンドウに

Chrome（や Edge）のウィンドウはタイトルで見分けますが、ブラウザのウィンドウのタイトルはアクティブなタブのものです。
本のタブがほかのタブと同じウィンドウにあると、TASlation はそのタブが前面にある間しか本を見られず、コマンドラインから始めたバッチは、
タブを切り替えるとウィンドウを見失います。

対策は一度だけで済みます。リーダーのタブをウィンドウの外へドラッグして（またはタブを右クリックして「タブを新しいウィンドウに移動」）、
専用のウィンドウにしてください。そのウィンドウはほかの作業の後ろに開いたままにしておきます。隠れていてもかまいませんが、最小化はしないでください。
デスクトップのビューアは独立したアプリなので、この対策は要りません。画像ビューアなどブラウザ以外のウィンドウは、ページをめくるたびにタイトル（ファイル名やページ番号）が
変わっても、同じウィンドウが開いている限り本として扱い、タイトルの変化では待ちません。ウィンドウが非表示か最小化されたときだけ、
ステータス行にそう表示して元に戻るのを待ちます。

それでもウィンドウが別のタブを表示していた場合、自動とバッチはタイトルの変化に気づき、ステータス行にそう表示して、本が戻るのを待ちます。
違うページを読むことはありません。`taslation batch` はビューアのウィンドウが現れるのも待つので（`--wait`、既定は10分）、
本を開く前に始めておけます。翻訳の段階ではビューアに触れません。

バッチには3つの安全策があります。

* 1つのビューアのウィンドウを操作できるバッチは同時に1つだけです（2つ目は始まらず、どのプロセスが使っているかを表示します）。
* 本のページらしくない画面は読みません。誤クリックで開いたストアのページ、おすすめ、別の本は形が違うので、帯にそう表示して待ちます。本に戻すか「読み終えた」を押してください。
  あとがきのような文字だけのページは、いつもページがある位置の紙で判断し、ページの上にパネルが開くと紙がその外まで広がって見えるので区別できます。
* バッチは何もクリックせず、キーも送りません。ページをめくるのはあなたです。

シリーズ設定などの前提情報を変えた後は、`taslation batch --retranslate` で全ページを読み直して訳し直せば、
巻全体に反映されます（キャッシュ済みのページは置き換えます）。

読み取りが巻末に達すると、ビューアによっては巻末のパネル（評価、次の巻）を表示します。矢印キーではこのパネルから出られないことがあるので、
そのときは「x」で閉じてから1ページ目に戻ってください。ビューア自身の部品や奥付のページのように見える文字（ラテン文字や数字の並んだ横書きの行）は、
台詞ではなく印刷物とみなして、そのままにします。

### 訳文のキャッシュとバックアップ

キャッシュは `~/.taslation/cache/<book>.json` にあり、
翻訳先の言語ごとに1ファイルです（書名はビューアのウィンドウのタイトルからとり、「書名」欄で変えられます。"My:Book 1" と "My
Book 1" のように同じファイル名になる本は `<book>-<hash>.json`）。「ツール」メニューの「保存した翻訳...」で、
キャッシュを一覧・削除できます。「削除」は選んだ行の本の、その行の言語のファイルだけを Windows のごみ箱に移します
（ほかの言語の訳文は残ります）。確認の既定のボタンは「残す」で、ごみ箱から元に戻せます。ごみ箱に移せないとき
（ごみ箱のないドライブなど）は何も削除せず、そう表示します。コマンドラインの `taslation cache delete` は従来どおり全言語を削除します。ファイルに入っているのは訳文、正規化した吹き出しの形と位置、ページ指紋、読者への訳注だけなので、
テキストエディタで開いて確かめてください。モデルが物語についてのノートを書いて残すことはありません（古い版が
`~/.taslation/series` に書いたノートのファイルは、読まずにそのまま残ります。要らなければ削除してかまいません）。

TASlation が読めないキャッシュ、ページ情報、シリーズ設定のファイル（壊れているもの、新しいバージョンで書かれたもの）は上書きしません。
`<name>.unreadable-<date>.json` として横に残し、コンソールに1行出して、新しいファイルに置き換えます。
本やシリーズを削除すると、こうした控えも削除されます。

本のキャッシュは、パスフレーズで暗号化したファイルにして、自分用の控えにしたり自分の別のパソコンに移したりできます（「保存した翻訳...」、
または `taslation cache export` と `taslation cache import`）。ファイルには訳文が入っているので、
自分だけで持っていてください。パスフレーズがなければ TASlation を含め誰も開けず、忘れたパスフレーズは取り戻せません。

* 書き出しと取り込みは、それぞれ警告から始まります。書き出したファイルはあなた専用で（本が自分のものでも、他人に渡せば著作者の権利の侵害になります）、
  取り込むのは自分のパソコンで自分が作ったファイルだけです。そこで「キャンセル」を押せば、ファイルを選ぶ前に止まります。
* パスフレーズは入力中に足りないものを表示し、「表示する」で伏せ字を外せます。全角スペースは半角スペースとして扱います。
  追加パッケージ `cryptography` がなければ、書き出しと取り込みは灰色になります。
* 取り込みのたびに、変更するキャッシュを `<cache>.before-import.<date>.json` として横に残すので、
  手作業で戻せます。パスフレーズが違う、ファイルが壊れている、本のキャッシュとしては大きすぎる（5,000ページ超、
  または1ページに500吹き出し超）、新しいバージョンの TASlation で作られたページを含む場合は、何も書かずに拒みます。
* `cache export` は、`--force` を付けない限り既存のファイルを上書きしません。

`cache export` と `cache import` は、パスフレーズの前に標準エラー出力へファイルの用途の説明を出すだけで、
それ以上は尋ねないので、スクリプトから無人で実行できます。`--confirm` を付けると「Continue? [y/N]」と尋ね、
yes 以外では何も読み書きせずに終了ステータス1で終わります。パスフレーズは表示せずに尋ねます。環境変数
`TASLATION_PASSPHRASE` はスクリプト専用です。PowerShell の PSReadLine は
`$env:TASLATION_PASSPHRASE = "…"` のような行を履歴ファイルに書き込むためです（秘密情報のフィルターは
"password" には反応しても "passphrase" には反応しません）。安全なのはコマンドのプロンプトで入力することです。
それでも変数を使うなら、値をコマンドラインに書かず、シェルに尋ねさせてください:

```
$env:TASLATION_PASSPHRASE = Read-Host -MaskInput               # PowerShell 7
read -rs TASLATION_PASSPHRASE && export TASLATION_PASSPHRASE   # bash, zsh
```

### ほかの言語への翻訳

翻訳先の言語は「翻訳先」欄（または `--language`、設定の `target_language`）で選びます。
キャッシュとシリーズ設定は言語ごとに保存され、写植はその文字体系のフォントに切り替わります。訳すモデルは翻訳先の言語で決まります
（「モデルの選び方」）。品質はその言語でのモデルの力によります。Qwen3.5 4B で試したときは、
スペイン語、中国語、韓国語は良好で、アラビア語は目に見えて劣りました。
インド系の文字は1文字ずつ描かれます（Pillow に同梱の文字組みエンジンが字形を整形しないため）。それ以外は、
右から左に書くアラビア語とヘブライ語も含め、正しく組まれます。

### コマンドライン

```
taslation                      TASlation のウィンドウを開く（`taslation gui` と同じ）
taslation gui --window "<タイトル>" --on-top   ビューアを選んだ状態で開き、ウィンドウをビューアの上に保つ（自動はオン。--no-auto でオフのまま開始）
taslation gui --reading        ビューアを選んだら読書モード（ページだけを全画面表示）で開始
taslation windows              取り込めるウィンドウの一覧
taslation doctor               モデル、フォント、Ollama、ネットワーク保護と、各段階が GPU と CPU のどちらで動くかを確認
taslation notice [--country CODE] [--reset]   起動時の法的な注意事項を、国（ISO コード）を指定して表示。--reset で次回の起動時にまた表示
taslation cache export <book> --out FILE [--force] [--confirm]   訳文のキャッシュを自分のパスフレーズで暗号化したファイルに書き出す（自分用の控えや自分の別のパソコン用）。--force で既存の FILE を上書き
taslation cache import FILE [--replace] [--confirm]    そのファイルをキャッシュに読み戻す（今の内容に統合、または置き換え）
taslation batch --window "<タイトル>" --book "My Book 1" [--max-pages N] [--no-context]   あなたがめくるページを読み取る。読み終えたら Enter、Ctrl+C で停止
taslation read --window "<タイトル>" --book "My Book 1"   1回取り込んで翻訳し、プレビュー
    （どちらも書名はビューアのウィンドウのタイトルからとる。ビューアの名前だけの "<ビューア> - Google Chrome" のように
     書名を含まないタイトルは拒否されるので、--book NAME を指定）
taslation translate page.png --show    自分の画像ファイルを翻訳（何も書き込まない）
taslation translate page.png --translator echo --no-translate   検出と OCR だけ
taslation review --book <book> [--notes]   要確認のキャッシュ済みの訳文（小さくしか組めない、表記の抜け、日本語よりずっと長いか短い、OCR に自信がない、辞書にない語）。--notes で読者への訳注も一覧
taslation cache list | delete <book> | path
taslation glossary list | show <series> | set <series> <term> <rendering> [--note ..] | delete <series> [term]
taslation glossary apply <series> --rename OLD=NEW [..] [--dry-run]   訳済みの部分で OLD を NEW に置き換える
taslation glossary font <series> "Comic Neue" | --clear   シリーズが提案する描画フォント（このパソコンにあるかを確認）
taslation glossary lettering <series> thought|shout|narration|handwritten|sfx [--family NAME] [--italic|--no-italic] [--bold|--no-bold] [--reset]
taslation batch --window "<タイトル>" --retranslate   今の前提情報で全ページを訳し直す
taslation gui --mode book --role translator   1冊まとめて先に翻訳するモード（既定は page）で、翻訳者として開始
taslation audit page.png       処理を実行し、発生したネットワーク通信をすべて表示
taslation annotations list [--json]          この PC に注記ファイルがある本の一覧（ページ数、枠の数、メモ、除外、読み順。本文は出しません）
```

全体のオプション: `--model NAME`（既定は設定の `ollama_model = "auto"`。翻訳先の言語でモデルが決まります: 「モデルの選び方」）、`--ollama-url http://127.0.0.1:11434`、
`--margins L,T,R,B`、`--font path.ttf`、`--uppercase`、`--language German`、
`--models-dir DIR`、`--config taslation.toml`。

`--window` は、ウィンドウのタイトル全体、ブラウザではタブのタイトル全体、タブのタイトルの先頭部分、ビューアらしいタブのタイトルの一部、
ウィンドウのタイトルの一部の順に照合します。複数のウィンドウが当てはまるときは推測せず、候補を表示して終了します（終了コード 2）。
タイトルをもう少し長く指定してください。

### モデルの選び方

既定（`ollama_model = "auto"`）では、翻訳先の言語がモデルを決めます。

| 翻訳先 | モデル（Ollama 名） | ダウンロード | ライセンス | 訳し方 |
|---|---|---|---|---|
| ブラジルポルトガル語とトルコ語以外のすべて | PLaMo 3 Translate 2B（Preferred Networks。`taslation-plamo3-translate-2b`、Q4_K_M） | 1.8 GB | PLaMo Community License | 1行ずつ |
| ブラジルポルトガル語、トルコ語 | Qwen3.5 4B（`qwen3.5:4b`） | 3.3 GB | Apache-2.0 | 約30行ずつ |

PLaMo 3 Translate は翻訳専用のモデルです。TASlation はその PFML3 形式のプロンプトを自分で組み、Ollama の `/api/generate` に
そのまま送ります（モデル自身のチャットテンプレートは翻訳先を指定できず、日本語に戻してしまうため）。1行ごとに1回の要求で、
前の台詞とその訳、参考情報としてシリーズ設定（話者を指定した行はその話者も）、その行に出てくるシリーズ設定の訳語を用語集として渡します。
コンテキストは 8192 トークン、GPU のメモリは約 1.9 GB です。OpenMantra（日本語から英語、1冊まるごと、シード固定で3回ずつ）では、
Qwen3.5 4B より chrF が 5.9 高く（ブートストラップの区間でおよそ +4.7〜+7.2）、速さは約2倍でした。
ブラジルポルトガル語とトルコ語は書けない（別の言語で答える）ので、この2つだけ Qwen3.5 4B が JSON のチャット形式で訳します。

入れておくのは翻訳先に要るほうの1つだけで済みます。install.cmd は最初の質問で翻訳先の言語を尋ね、その言語のモデルを取得します。
ウィンドウの一覧の番号か英語の名前で答えます（一覧にない言語も、PLaMo か Qwen が書ける言語なら名前で選べます）。Enter なら、
ウィンドウで最後に選んだ言語、なければこの PC の表示言語に合う言語、なければ英語です。`taslation.toml` に `target_language` があれば、
尋ねずにそれを使います。表示されたものと違う言語を選ぶと、ウィンドウもその言語で始まります（`ui.json` に書きます）。
install.cmd の質問は、Windows の表示言語が日本語なら日本語で表示します（訳文は `installer-texts.json` にあり、ほかの言語も足せます。
訳のない言語では英語です）。
「To:」で別のモデルが要る言語を選ぶと、ウィンドウがそのモデルのダウンロード（大きさを表示）と、要らなくなったほうの削除を提案します。
TASlation が入れる翻訳モデルは一度に1つだけです。TASlation が入れたのではないモデル（もともとあなたが入れていた `qwen3.5:4b` など）は、
消すかどうかを別に尋ね、既定では残します。PLaMo を初めて入れるときは、先にそのライセンスへの同意を尋ねます。
本の上に重ねているあいだ、読書モードのあいだ、1冊まるごとの実行中は尋ねず、ウィンドウに戻ったときに尋ねます。
コマンドでは `--language` で同じことを尋ね、`python setup_models.py --translator-for "Turkish"` でも入れられます。
`ollama_model` に自分のモデル名を書いているときは、何も提案しません。
PLaMo が入っておらず Qwen があるときは、そのあいだ Qwen で訳し、ページの上の帯にそう表示します。
翻訳先に要るモデルが入っておらず代わりもないときは、帯にそのモデルが入っていないことを表示します。どちらの場合も、帯の
「モデルをダウンロード」で、install.cmd を実行し直さずにその場で入れられます。
`ollama_model` にほかのモデル名を書けば、そのモデルをチャット形式のプロンプトで使います（以下はそうした選び方の記録です）。

どちらのモデルも訳すだけです。巻の翻訳ノートを書く、訳を見直す、長すぎる訳を短くする、別案を出すといった、
モデルへの追加の要求はしません（2026-11-06 に廃止）。日本語をそのまま返した行や抜けた行だけは、自動で訊き直します。

以下は、2026年11月まで既定だった Qwen3.5 4B を選んだときの記録です。

文字は OCR モデルが読むので、言語モデルが見るのは文字です。言語モデルに画素は一切送りません。テキスト専用のモデルでもかまいません。画像対応のモデル（Gemma 4、
Qwen 3.5/3.6、Ministral 3）の視覚部分の重みは、4B では負担が小さく、9B 以上では大きくなります。バッチに必要なのは、
翻訳の質に加えて、長いコンテキスト、幅広い言語への対応、用語集に従う力です。

候補は、日本語から英語への翻訳を専門に採点する唯一の公開ベンチマーク
[JP-TL-Bench](https://github.com/shisa-ai/jp-tl-bench)（LLM による一対比較、
0〜10の「LT」スコア。数値は [論文](https://arxiv.org/abs/2601.00223) の JA→EN 方向）から、
普通のパソコンで動くテキスト専用の公開モデルを選びました。

| モデル（Ollama 名） | JA→EN LT | ダウンロード | コンテキスト | ライセンス |
|---|---|---|---|---|
| `qwen3:30b-a3b-instruct-2507-q4_K_M`（最高品質） | 9.77 | 19 GB | 256K | Apache-2.0 |
| `hf.co/XpressAI/shisa-v2.1-unphi4-14b-GGUF:Q4_K_M` | 9.36 | ~9 GB | 16K | MIT |
| `hf.co/XpressAI/shisa-v2.1-qwen3-8b-GGUF:Q4_K_M` | 9.02 | ~5 GB | 40K | Apache-2.0 |
| `qwen3:8b` | 7.94 | 5.2 GB | 40K | Apache-2.0 |
| `qwen3:4b-instruct-2507-q4_K_M` | 記載なし（4B のベース: 5.34） | 2.5 GB | 256K | Apache-2.0 |
| **`qwen3.5:4b`**（ブラジルポルトガル語とトルコ語の既定） | 記載なし | 3.3 GB | 256K | Apache-2.0 |

`qwen3.5:4b` は、実際の巻を使った 4B
クラスのモデルの勝ち抜き戦で勝ちました（`docs/OFFLINE_VERIFICATION.md` の「Lighter models compared」と「A knockout among the 4B models」）。
バッチと同じ方法で訳すと、その訳は Qwen3 4B の最良のビルドと同じくらい 30B の訳に近く（401行で chrF 45.7。
Qwen3 4B は Q6_K で 46.2、Q4_K_M で 44.5）、シリーズ設定にも同じくらいよく従い（45のチェック中39。30B は41）、
その中で最も速いモデルです。Ollama の KV キャッシュを量子化すれば（「インストール」参照）、6 GB の
GPU でバッチの 16K のコンテキストを保ったまま毎秒60トークンで生成し、同じマシンの 30B の約4倍の速さです。視覚部分の重みは使わず、
思考モードは要求ごとにオフにしています。30B を判定役にしたブラインド評価では、
Qwen3 4B は 30B をわずかに下回りました（162行のうち 30B の訳が89行、Qwen3 4B の訳が63行で好まれました）。

最高の品質を求めるなら `qwen3:30b-a3b-instruct-2507-q4_K_M` です。アクティブなパラメータが 3B の MoE で、
約 20 GB の RAM が必要ですが、GPU のメモリはあまり使いません。開発に使ったマシンでは、短いコンテキストで毎秒17トークン、
バッチの 32K のコンテキストで毎秒11トークンで生成します。RAM に余裕があれば取得して、`ollama_model` と
`ollama_num_ctx = 32768` を設定してください。ほかの候補は次のとおりでした。

* Shisa V2.1 8B（日英向けの調整で、ほかの翻訳先は想定外）は品質では 30B に並びますが、密なモデルなので、
  実用的なコンテキストでは 6 GB のカードに収まりません。
* Hy-MT2（`kaelri/hy-mt2`。翻訳専用）は 1.8B でさらに速いものの明らかに劣り、
  7B は長い要求で吹き出しを混ぜてしまいます。
* TranslateGemma 4B は構造化した要求に従いません（40回の要求で、まともな訳は1回）。
* Index-Translate（`hf.co/IndexTeam/Index-Translate-2B-GGUF:Q4_K_M` と 9B）も負けました。2B は8行に1行を訳さずに残し、
  9B は 6 GB のカードに収まらず5倍遅いうえ、30B に近づきません。
* JP-TL-Bench でこれより高いのは `ministral-3:14b`（9.88）だけですが、視覚部分の重みを含み、
  快適に使うには 12 GB の GPU が必要です。Gemma 4、Qwen 3.5、TranslateGemma は
  JP-TL-Bench に載っていません。日本語の総合リーダーボード Nejumi 4 では、Qwen3.5-9B（0.749）が Gemma 4
  E4B（0.669）を大きく上回っています。

モデルは `--model NAME` か設定ファイルの `ollama_model` で切り替えます（`"auto"` で翻訳先の言語による選択に戻ります）。

### 設定

よく変える設定は、ウィンドウの「ツール > 設定...」で変えられます。写植の最小と最大の大きさ、これより小さく組んだ訳文を見直しの一覧（レビュー）に入れる大きさ、
写植の大きさ（80〜130 %。100 % は吹き出しに収まる最大の大きさのままで、90 % ならすべての訳文を1割小さく組みます。
100 % より大きくしても、吹き出しと最大の大きさは超えず、ページ内で大きさをそろえるために抑えられていた訳文だけが大きくなります。
設定ファイルでは `text_scale`、本ごとの値は翻訳者モードの「この本の設定...」）、大文字で組むか、傾いた文字を同じ傾きで組むか、ウィンドウの文字の大きさ、常に手前に表示するか、本の始め方（1ページずつか、先に1冊まるごとか）、
任意のページ用モデル（レイアウトモデルとインペイント）を使うかどうかです。ほかの機能の設定（ポインターを置いた吹き出しの拡大表示、1冊まるごとの読み取りが終わったときのタスクバーのボタンの点滅と音）も、ここに並びます。
インペイント（絵の上の文字を LaMa で消して絵を補う）は「使わない」「GPU があるときだけ」「いつも使う（CPU でも）」から選びます。既定は「GPU があるときだけ」で、
モデルが入っていて、TASlation が使える GPU（CUDA が使える NVIDIA の GPU。PyTorch が CUDA で使えるもの）があるパソコンでだけ使います。
そうでないパソコンでは「使わない」と同じ消し方になり、このモデルを読み込むこともありません（その場合は、設定の欄にその旨を表示します）。
`install.cmd` は、NVIDIA の GPU があるパソコンには PyTorch の GPU 版（CUDA 版）を入れるので、そのまま「GPU があるときだけ」で使います。
GPU のないパソコン（AMD と Intel の GPU も GPU として数えません）、ドライバーが古いパソコン、GPU 版が動かなかったパソコンには CPU 版を入れ、そこでは使いません（README の「インストール」）。
この版より前のインストールで CPU 版が入っているパソコンでは、`install.cmd` を実行し直すと GPU 版に置き換えます。`update.cmd` のあとのインストールは置き換えず、そう表示します。
「いつも使う（CPU でも）」なら GPU がなくても使いますが、1画面に約4秒かかります（GPU では約0.6秒）。
レイアウトモデルは、もっと多くの本で測るあいだは既定で使いません。どちらのモデルも、学習に使った画像の出どころを明らかにしていません（`docs/THIRD_PARTY.md`）。
2つのモデルは1つの質問でまとめて入れます（`install.cmd` が、その出どころのことを示してから尋ねます）。TASlation が GPU で LaMa を使うパソコン（GPU 版の PyTorch が入る、または入っているパソコン）では
Enter で入れ（[Y/n]）、それ以外では Enter で入れません（[y/N]）。コンソールのない実行では、どちらでも入れません（`-Yes` もこの質問には答えません）。
`python setup_models.py` を手で実行したときも同じように尋ね、Enter の意味は PyTorch が CUDA の GPU を使えるかどうか（「GPU があるときだけ」と同じ判断）で決めます。`--agreed` を付けると尋ねずに入れます。
「保存」を押すと `taslation.toml` に書き込み、すぐに反映します（表示中のページは、キャッシュから組み直します）。ファイルのコメントやほかの行は、そのまま残ります。
ウィンドウの文字の大きさは保存した時点で変わりますが、すべての部分に行きわたるのは再起動の後です。

「設定ファイルを開く」は、すべての設定が載った `taslation.toml` をテキストエディターで開きます。ファイルがなければ、先に `taslation.toml.example` から作ります。
作ったファイルでは、どの設定も行頭に `#` が付いた説明の状態で、`#` を消すとその設定が有効になります（既定値を書き込まないので、後のバージョンで既定値が変わっても、それに従います）。
作る場所は、設定を読み込む場所と同じです（読み込んだファイル、なければ状態フォルダの `taslation.toml`。状態フォルダは更新しても残ります）。
`update.cmd` で更新しても、TASlation のフォルダーにある `taslation.toml` は上書きしません（README の「更新」）。
ファイルで変えた設定は、次の起動から反映されます。

「設定」の「ショートカット」ページでは、ウィンドウのキーを変えられます。一覧で操作（表示中のページを翻訳、読書モード、元に戻す、やり直す、
メニューのコマンド、翻訳者モードの道具とページ上のキー（次の領域・前の領域、領域を 1 ピクセル動かす、書式と領域のコピー・貼り付け）、
領域の編集画面の「前へ」「次へ」など）を選び、「キーを変更...」を押してから新しいキーを押します（Esc で取り消し）。
「キーなし」でキーを外し、「既定値」でその操作のキーを、「すべて既定値に」ですべてのキーを最初のものに戻します。
ほかの操作のキー、ビューアに渡すページ送りのキー（矢印、PageUp、PageDown、Home、End、スペース。修飾キー付きも）、Esc、Tab、F10、Alt+F4 は使えません
（Tab と Shift+Tab、Alt+矢印キー、ページの Ctrl+C / Ctrl+V は、最初からその操作のキーになっているものだけ、その操作に使えます）。
ウィンドウ全体で使うキーと、領域の編集画面でも使うキー（「前へ」「次へ」、書式のコピーと貼り付け）は、Ctrl か Alt と組み合わせるか F キーにします
（単独のキーだと入力欄で文字が打てなくなるため）。ページの操作と領域の編集画面だけの操作は、働く場所が違うので同じキーでもかまいません（Alt+↑ / Alt+↓ がそうです）。
ページで使うキー（枠の編集・削除・文字列の方向と、翻訳者モードの道具）は単独のキーでもかまいません。翻訳者モードの道具のキーは、翻訳者の役割のときだけ働きます。
キーは「保存」で状態フォルダの `shortcuts.json` に保存し（最初と違うキーだけ）、すぐに反映します。メニューとツールバーのボタン、翻訳者モードのボタンと説明、領域の編集画面の「前へ」「次へ」、
「ヘルプ > 使い方」の「キー」（「ヘルプ > キー一覧...」）も、変えたキーを表示します。
Esc とページ送りのキー、翻訳者モードのマウスの操作は灰色で表示するだけで、ここでは変えられません（ページ送りのキーは「ページ > ページ送りのキー...」）。全画面のビューアの上にいるときの F5、F11、Esc は元のキーのままです。

「設定」の「システム」ページには、ページの処理の段階（文字の検出、文字の読み取り、翻訳、消去と写植）ごとに、どこで動くか（「GPU（GPU の名前）」か「CPU」）と、1ページにかかった秒数を表示します。
検出は従来の検出が CPU で、レイアウトモデルを使うときはそのモデルが GPU で動きます。OCR は CPU で動きます。翻訳は Ollama が読み込んだモデルの場所で、
一部だけがビデオメモリーに載っているときは「GPU と CPU（60 % が GPU）」のように表示します（モデルが読み込まれていなければ、その旨を表示します）。
消去は紙の色の塗りつぶしが CPU で、インペイント（LaMa）を使うときは絵の上が GPU で動きます（「いつも使う（CPU でも）」で GPU がなければ CPU）。GPU として数えるのは CUDA が使える NVIDIA の GPU だけで、
調べるためにモデルを読み込んだり Ollama を起動したりはしません。秒数は最近写植した20ページの平均で、ウィンドウを閉じるときに状態フォルダの `timings.json` に保存します（数値だけで、ページの内容は入りません）。
「もう一度調べる」で表示を更新します。同じ内容は `taslation doctor` も「Where each stage runs:」として出力します。

設定ファイル `taslation.toml` は、`--config` で指定したもの、実行したフォルダの `./taslation.toml`、状態フォルダ（`~/.taslation`、
または環境変数 `TASLATION_STATE_DIR` の場所）の `taslation.toml` の順に探し、最初に見つかったものを読みます（どれもなければ既定値）。
状態フォルダに置いてください。どのファイルを読んだかは `taslation doctor` が表示します。

作業ディレクトリかこのフォルダーに `taslation.toml` を置くと読み込みます（任意）:

```toml
ollama_model = "auto"        # "auto": PLaMo 3 Translate 2B, or Qwen3.5 4B for Brazilian Portuguese and Turkish; or a model of your own
ollama_num_ctx = 16384       # the chat translator's context window (a batch request needs ~10K); PLaMo has its own (8192)
target_language = "English"
uppercase = false            # scanlation-style capitals (Latin script only)
readable_font_size = 11      # a translation set smaller than this is flagged "small" for review (0 = never)
text_scale = 1.0             # the lettering size: 0.9 a tenth smaller, 1.2 larger where the page held it back (a book can have its own)
enforce_terms = true         # a translation that misses a rendering from the series sheet is flagged "rendering"
spellcheck = true            # flag a word the dictionary does not know (needs `pip install pyspellchecker`, offline word lists)
take_columns_beyond = false  # dark bubbles: also read a column that goes on past the interior on the bubble's own black (a book setting too)
next_page_key = "Left"       # key that shows the next page in your viewer
context_mode = true          # batch: read the whole book first, then translate it with the whole story as context
chunk_bubbles = 30           # lines per translation request in context mode (3-5 pages)
erase_mode = "fill"          # "fill": the bubble's own paper, flat or along its shading, within its outline;
                             # "inpaint": the same way, inpainted; "classic": the erase before 2026-10-30, byte for byte
art_erase = "auto"           # with "fill", lettering on the drawing is inpainted by LaMa once installed: "auto" only where PyTorch has a CUDA GPU (else as "off"), "lama" also on the CPU, "off"
detect_model = "off"         # (opt-in for now: "auto") the layout model first, the classical detectors add what it missed: "auto" (where art_erase runs), "on", "off"
ollama_keep_alive = "5m"     # how long Ollama keeps the model after a request: "2h", "90s", seconds; "-1" never
                             # unloads, "0" unloads after every request
ocr_threads = 0              # CPU threads for the OCR model (0 = torch's default, one per core); while
                             # other programs keep the CPU busy, half the cores can be faster
font_path = ""               # auto: the series sheet's font where installed, then models/fonts per script, then system fonts
flash_when_done = true       # a whole-book run that ends while TASlation is not in front flashes its taskbar button
sound_when_done = false      # ... and plays the system's default sound
```

ウィンドウの文字の大きさは `ui_scale` で変えられます（1.0 が Windows の拡大率どおり。0.5〜3.0）。
起動時に、ウィンドウのあるモニターの拡大率に掛けて使い、拡大率の違うモニターへウィンドウを移したときも、そのモニターに合わせて文字の大きさを変えます。
ピクセルで描く部分（ページ、ページの一覧の枠など）は、元の大きさのままです。

キーはすべて `taslation/config.py:Settings` のフィールドで、
`taslation.toml.example` に全項目と既定値が載っています。廃止した設定（`review_pass`、`series_notes`、
`notes_pages_per_request`、`revision_flag_distance`、`revision_changes_only`、`ollama_prompt_style` など）が設定ファイルに残っていても、読み込みはそのまま通り、何もしません。
このバージョンが知らないキー（綴りの誤りや、新しいバージョンの設定）があっても、起動は止まりません。そのキーは読み飛ばし、ウィンドウが一度だけキーの名前を知らせます（値は表示しません）。
コマンドラインでは、そのたびに警告として表示します。旧名の `~/.selftrans` フォルダ（さらに古い
`~/.cleantrans` も）は初回起動時に `~/.taslation` へ移し、`SELFTRANS_*` 環境変数も、
`TASLATION_*` がなければ引き続き読み込みます。

### OCR モデルとそのライセンス

ページの文字は3つの OCR モデルが読みます（合わせて約 700 MB）。manga-ocr-charspot-small は文字を1字ずつ見つけて読むモデルで、
長い台詞に強い一方、文字のない絵からも何か読もうとします。そこで TASlation はまずこのモデルの確信度
（文字の中心らしさの平均と文字の見分けの確かさの平均の積。`ocr_min_confidence`、既定 0.65）と、
そのページのふつうの文字の大きさの3倍以下であること、2文字以上であることを確かめ、外れたものは文字ではないとして扱います。
1文字だけの台詞はこのため読み飛ばされます。そのときは翻訳者モードで領域を手で追加してください。手で追加した領域には、
この確認は一切かかりません。

確認を通った領域は manga-ocr-nar-small も読みます。2つの読みが同じならそれを採ります。違えば manga-ocr-base-CPT-flex も読み、
3つのうち、ほかの2つにいちばん近い読みを採ります（同点なら charspot、次に nar）。3つとも大きく違うときは、
その行に「読み違えているかもしれません」の確認フラグを立てます。手で追加した領域は3つのモデルがすべて読みます。

3つのモデルの重みのライセンスはどれも **CC BY-NC-SA 4.0** で、**非営利の利用に限られます**。TASlation のコードは MIT ですが、
ページを読むにはこれらのモデルが必要なので、TASlation を使うにはこの条件に同意する必要があります。`install.cmd` が条件を示して
1回だけ同意を尋ね、同意しなければ何もインストールせずに終了します（`-Yes` でも同意したことにはなりません）。重みはリポジトリには含まれず、
アプリケーションがダウンロードすることもありません。ダウンロードするのは `setup_models.py` だけです。

`setup_models.py` は、大きなファイルの進み具合をパーセントと MB で表示します。接続が途中で切れたときは、同じ実行の中で3回まで、
切れたところから続けます（サーバーが HTTP の Range に応じる場合。応じなければ最初から取り直します）。OCR モデル、ページ用モデル、
フォントは、失敗しても途中までのファイル（`.part`）を残し、次の実行で続きから取得します。続きから取ったファイルも、
ファイル全体のチェックサムを確かめてから置きます。PLaMo のファイルは、失敗したときや中止したときには途中までのファイルも消します
（ウィンドウからのインストールは何も残さないため）。winget で Python と Ollama を入れるときは、質問への Y を winget の
利用条件への同意として渡します（`--accept-source-agreements --accept-package-agreements`。質問の前にそう表示します）。

以前のインストールで manga-ocr-charspot-small しかない場合も、TASlation はそのモデルだけで動きます。ステータス行にその旨が1行出るだけで、
エラーにはなりません。`install.cmd` を実行すると残りの2つが入ります。

OCR はすべて CPU で動き、3つのモデルが `ocr_threads` の設定を共有します。GPU は Ollama のために空けておきます。CPU がほかの作業で
忙しいときは、`ocr_threads` をコア数の半分にすると速くなることがあります。

Ollama のモデルは必要なときだけ GPU メモリに載せます。起動時には読み込まず、翻訳が必要な行が出たときに読み込みます
（数秒かかり、状態表示に出ます）。翻訳がキャッシュにあるページでは読み込みません。読み込んだモデルは最後の要求から
`ollama_keep_alive`（既定 "5m"）の間残り、そのあと自動で解放されます。未翻訳のページを読み進めている間は要求のたびに
延長されるので、ページごとに読み込み直すことはありません。一冊通しの処理では、ページを読んでいる間はモデルを読み込まず、
読み終えてメモと翻訳に移るときに読み込みます。処理の終わり（停止や失敗を含む）とウィンドウを閉じたときには、すぐに解放します。
`ollama_keep_alive = "-1"` にすると以前と同じく、起動時に OCR モデルより先に読み込み、解放しません。
読み込んだモデルの一部しかグラフィックボードに載らなかったときは、もう一度読み込み直し、それでも載らなければその旨を知らせます。

### 本がなくても試すには

`python tools/fake_viewer.py` は、合成したテストページを表示する代用のビューアを開きます（左矢印で次のページ）。
TASlation で「Fake Viewer」というタイトルのウィンドウを選ぶと、取り込み、1冊まるごと読む処理、
ページキーの受け渡しが一通り動くことを確かめられます。

### エラーの記録と「詳細をコピー」

ウィンドウは、状態フォルダの `log.txt` にエラーを記録します（大きくなると次のファイルに移り、古いものから消えるので、全部で 1 MB ほどです）。
起動時の動作環境（TASlation のバージョンと日付、Python、Tk、Windows、torch とグラフィックボード、Ollama のバージョン）、既定値から変えた設定の名前と値、
警告、エラーとその発生箇所（プログラムのファイル名と行）を書きます。
ページの文字、OCR の結果、訳文、書名、ウィンドウのタイトルは書きません。ファイルの場所は、状態フォルダやモデルのフォルダを名前（`<state dir>` など）で書くだけで、
その先のファイル名や、ほかの場所は `<path>` に置き換えます。エラーの文中の引用や、ASCII 以外の文字（日本語など）は `…` に置き換えます。

「ヘルプ > TASlation について」と、エラーを知らせる画面にある「詳細をコピー」は、同じ内容（動作環境、変えた設定、最後のエラー）をクリップボードに入れます。
不具合を報告するときに貼り付けてください。どこにも送信しません。起動できなかったときの画面でも、「はい」でコピーできます。

## オフラインで動くことを自分で確かめる

1. `taslation doctor` が
   `Network guard: ON (loopback:11434 only ...)` と出力することを確かめます。
   ウィンドウでは「ヘルプ」メニューの「TASlation について」で同じ状態を確認できます。ステータスバーに表示が出るのは、
   保護が接続の試みを遮断したときだけです（その後はウィンドウを閉じるまで残ります）。
2. `taslation audit tests/fixtures/sample_page.png --translator echo` は、
   検出と OCR の処理全体を実行し、プロセスが行ったネットワーク通信をすべて表示します。echo の翻訳器では一覧は空になり、
   Ollama を使うと `127.0.0.1:11434` だけが表示されます（モデルを読み込むウォームアップの要求と、ページの要求）。
3. テストスイートには、
   プロセスの中から生のソケットで外部のアドレスに届かないことを確かめるテストがあります（`tests/test_netguard.py`）。
4. Wi-Fi を切るかケーブルを抜いて、いつもどおりに使ってください。Ollama は応答を続け、OCR モデルは
   `models/` から読み込まれます。

`docs/OFFLINE_VERIFICATION.md` に、手順と、開発時に行った検証の結果を記録しています。

## 仕組み

詳しくは `docs/ARCHITECTURE.md` を参照してください。概要: 320ビットの知覚的なページ指紋で画面のページを識別し（見開きなら1ページずつ。指紋はそのページの紙の上の墨の範囲で、暗い背景のビューアではページの大きな明るい部分とそれに並ぶものを紙とみなします。範囲の中の文字はどれも、その上か下か隣にあるページのものとして扱います）、
キャッシュにあれば保存した訳文をライブのページに重ねます。なければ、OpenCV による吹き出しの検出、OCR、
Ollama のモデルによる翻訳（シリーズ設定と直前のページを文脈に。PLaMo は1行ずつ、Qwen はページごとに1回）、消去と写植を行い、得られた訳文をキャッシュに保存します。
バッチは同じことを、上で説明した2つの段階で1冊まとめて行います。ウィンドウのアイコンは `tools/make_icon.py` が
Pillow だけで描き、`taslation/ui/assets/` に置いています。絵を変えたら実行し直してください。

## 制限事項

* 検出は古典的な画像処理です。対象は、閉じた吹き出しと枠（明るいものも暗いものも。暗い吹き出しや暗い部分の明るい文字は白で写植します）と、
  ページに直接書かれた台詞や効果音です。ページに直接書かれた文字は、文字とその周りの明るい背景だけを消し、細い線や網点も含めて隣の絵は残し、
  空いた所に訳文を組みます。絵が近いと訳文は小さくなり、文字の一部と取り違えた小さな絵は一緒に消えます。
  同じ濃さの込み入った絵に入り込んだ文字は見落とします。`translate_sfx = false` にすると、
  手描きの効果音は描かれたまま残します。ニューラルネットの検出器を同梱しない理由は `docs/THIRD_PARTY.md` にあります。
* 接したり重なったりして1つの白い部分になっている吹き出しは、くびれた所や、輪郭線が両側から鋭く内側に曲がる所で切り分け、それぞれ別に訳します。
  1つの吹き出しに2組の列がある場合は1つの領域のままです（`split_joined_bubbles`、この本の設定でも変えられます）。
  以前のバージョンでキャッシュしたページは、接した吹き出しの組に訳文を1つしか持たないので、「訳し直す（キャッシュを使わない）」で訳し直してください。
* OCR の精度は文字の大きさにほとんど左右されません（きれいな縦書きなら 12 px も 28 px と同じように読め、
  切り出しを拡大しても変わりません）。精度を下げるのは、スクリーントーンの上の文字、装飾的な書体、そもそも文字ではない領域で、これらは検出の問題です。
* 消去は吹き出しの輪郭線の内側にとどまり、吹き出しの紙の色（クリーム色や陰影も）で塗るので、
  アンチエイリアスで途切れた細い輪郭線を塗りつぶすことはありません（テスト用の巻では、吹き出しの外で変わった画素が67,624から19,882に、
  途切れた輪郭線の画素が13,398から166に減りました）。`erase_mode = "classic"` で以前の消去方法に戻せます。
  輪郭線そのものに描き込まれた文字、輪郭のはっきりしない部分（インクの飛び散りなど）、小さな吹き出しの1〜2文字は消し残すことがあります。
* OCR モデルが当て推量でしか読めない領域（顔、ハイライト、読めない効果音）は、確信度のフィルター（`ocr_min_confidence`）で捨てます。小さな領域（`min_short_bubble`、
  60 px 未満）の1〜2文字は絵の点などとみなしますが、確信度0.95以上で、ひらがなか漢字で始まり、
  輪郭線のある吹き出しにある短い台詞は訳します。小さな領域のカタカナ（ほとんどは描き文字の効果音の一部）と、単独の記号（感嘆符、
  三点リーダー）は描かれたまま残します。
* 取り込むのはページの部分だけにしてください（Chrome で読むビューアなら、
  ブラウザのタブとアドレスバーを除けば十分です。リーダー自身のツールバーは自動で無視します）。見開きは2ページに分けます。暗い背景のビューアでは、下半分が黒いコマのページでも、明るい部分と並ぶ吹き出しやコマまでを1ページとして取り、リーダーのスライダーやボタン、帯は取り込みません。ページの端がビューアと同じ黒だとそこだけページの外になりますが、その文字は隣のページの一部として読みます。範囲の中でどのページにも属さない文字は最も近いページのものとして読むので、リーダー自身の帯は範囲から外してください。リーダーがヘッダーやページスライダーをページの上に表示している間は、帯ごと読むのでページ指紋が変わります。
* 内側にスクリーントーンや暗い色がある吹き出し、輪郭線が途切れた吹き出しは、見落とすことがあります。
* 訳の質は Ollama のモデル次第です。大きなモデルほど上手で、そのぶん遅くなります。バッチは、
  読むときに速さが問題にならないようにするためのものです。モデルが苦手な言語では訳が劣ります。
* 名前の表記はシリーズ設定に書いたときだけそろいます。書いていない名前は、モデルが行ごとに読むので、表記が揺れることがあります。
  要確認の印や「検索と置換...」で見つけて、シリーズ設定に加えてください。
* ページ指紋はウィンドウの大きさやビューアの背景の違いには強いものの、
  単ページ表示と見開き表示の切り替えには対応しません（見開きは2ページに分けるので、見開きでバッチ処理したページは単ページ表示でも見分けられますが、
  逆はできません）。
* 取り込みは Windows 専用です。ほかの OS では `translate` コマンドで画像ファイルを処理できます。
