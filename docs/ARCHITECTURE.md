# Architecture

```
viewer window ──capture──▶ page image (memory only)
                              │
                              ▼
                      fingerprint.analyze       locate page(s), 320-bit hash per page
                              │
              ┌───────────────┴───────────────┐
              ▼ cache hit                      ▼ cache miss
   cache.lookup(fingerprint)         detect.BubbleDetector (OpenCV)
   reuse stored translations                  │
   match to live bubbles by IoU               ▼
              │                      ocr.Readers (three models, local files, CPU)
              │                               │  keep only Japanese results
              │                               ▼
              │                      translate.models.make_translator (127.0.0.1:11434):
              │                        PlamoTranslator (one raw PFML3 request per line) or
              │                        OllamaTranslator (pt-BR, tr, a model of one's own: one request per page)
              │                               │
              │                               ▼
              │                      cache.add(page) + save (merged with the file)  → ~/.taslation/cache/<book>.json
              └───────────────┬───────────────┘
                              ▼
                 render.erase_region + render.letter_text
                              │
                              ▼
                      translated image (memory only) → Tk canvas
```

The window shows the viewer live (its latest capture, the translation laid over it while it shows a translated
page). While a page is translated, `Pipeline.process(events=...)` tells it how the page fills in: the regions
once found, each one read, each one lettered as the model's streamed answer brings its translation, then the
finished page.

What the working parts say (the batch's progress, the pipeline's stages, a failed request, a missing model, a
viewer that draws nothing) is a `taslation.messages.Message`: a stable dotted code (`batch.scanning_page`,
`ollama.unreachable`, ...) and its params (numbers and short strings, never text of the book), registered with
their English templates in `messages.py`. A window maps the code to its own catalog (`messages.render(message,
catalog)` does it, English where the catalog has no entry); `str(message)` is the English fallback, and since
`Message` is a `str`, code that knows nothing of codes shows it as the string it always got.

| `taslation/detect/tilt.py` | Lettering set at a slant. `lettering_tilt` measures how far a region's lettering is turned (`TextRegion.angle`, degrees counter-clockwise) from the glyph-sized pieces of the ink in its text box and mask: the ink is turned through ±45° (1° steps, then 0.25° round the best) and projected onto both axes, and the angle is where the product of the two projections' sharpness (the sum of the squared counts) peaks: the lines pile up across, the glyphs set in step along them. The axis the turning sharpens the most tells columns from rows. An angle of `DEAD_ZONE` (3°) or less, a confidence (`1 - upright / best`) under `MIN_CONFIDENCE`, fewer than `MIN_PIECES` glyph-sized pieces or lines shorter than `MIN_RUN` line widths count as upright: angle 0, and the region takes the straight path of before, byte for byte. A short word (too few pieces or too short lines for that search: two to four glyphs, a short column or row) is measured by `short_tilt` instead, as a text detector measures a line (the line quad of DBNet, PaddleOCR and the comic text detector): the minimum-area rectangle round its ink (its angle taken from the corners, never OpenCV's own angle, whose convention changed in 4.5.1), checked against the principal axis of the ink's second moments and the angle of the sharpest projection across the line. It is slanted only when all three agree within `SHORT_AGREE` (2°), the rectangle is `SHORT_ELONGATION` times as long as wide and `SHORT_GAIN` smaller than the upright box, the ink is one line, and the mean lies past the dead zone (`Tilt.short`). On OpenMantra (straight lettering) it slants 3 of 390 short regions read as text; it finds about four in ten short words turned by 8–20°, most four-glyph ones and few two-glyph ones (a small kana or a mark set off the line pulls the measures apart, and the word stays upright). `Upright` turns a crop by `-angle` with the room it needs and maps points both ways. `Pipeline._measure_slants` measures every region before the reading (`Settings.slant_text`); a region from the cache keeps its stored angle. The OCR reads a slanted region turned upright (`Pipeline._upright`: cut to the frame of its ink), a model region's characters are mapped back onto the page as turned boxes (`TextRegion.char_quads`, which the erase of a tier-3 region fills). |

Where two names give one file name ("Pebble:Harbor 1" and "Pebble Harbor 1"; "QUILLPOND 1" and "Quillpond 1" on Windows), the second
name's file has `<name>-<hash>` in place of `<name>` (`names.py`).

There is deliberately no way to save a page or a translated page to disk.

Nor is there a way to read a page in TASlation without the viewer: reading is on the viewer only. Outside a running
whole-book run the page area shows the viewer's current frame and nothing else, with the cached translation laid over
it while the page fingerprint matches; no page is shown from memory. A run's page images are shown only as its
progress - while it reads, the page the viewer shows as the run takes it; while it translates, the page being
translated, lettered line by line - and the page area goes back to the live view the moment the run ends, however it
ended. The strip's thumbnails are a sign of progress and cannot be opened: a click says to open that page in the
viewer. After the run the images serve only the erase done ahead, for a page the viewer shows (`Pipeline.erased_ahead`).
The reason is the same as for the cache: a book paged through in TASlation's window away from its viewer would be read
outside the conditions it was sold under, which matters where what is paid depends on what is viewed; read in the
viewer, it is read under the same conditions as by a reader in Japan.
