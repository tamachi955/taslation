# Architecture

```
viewer window ──capture──▶ page image (memory only)
                              │
                              ▼
                      fingerprint.analyze       locate page(s), 320-bit hash per page
                              │
              ┌───────────────┴───────────────┐
              ▼ cache hit                      ▼ cache miss
   cache.lookup(fingerprint)         detect.BubbleDetector (OpenCV)
   reuse stored translations                  │
   match to live bubbles by IoU               ▼
              │                      ocr.Readers (three models, local files, CPU)
              │                               │  keep only Japanese results
              │                               ▼
              │                      translate.models.make_translator (127.0.0.1:11434):
              │                        PlamoTranslator (one raw PFML3 request per line) or
              │                        OllamaTranslator (pt-BR, tr, a model of one's own: one request per page)
              │                               │
              │                               ▼
              │                      cache.add(page) + save (merged with the file)  → ~/.taslation/cache/<book>.json
              └───────────────┬───────────────┘
                              ▼
                 render.erase_region + render.letter_text
                              │
                              ▼
                      lettered patches (memory only) → see-through window over the viewer
```

TASlation's lettering lies over the viewer's own window (the parts of the lettered page that differ from the frame,
shown while the viewer shows that page), and its own window is never on the screen. While a page is translated,
`Pipeline.process(events=...)` tells it how the page fills in: the regions
once found, each one read, each one lettered as the model's streamed answer brings its translation, then the
finished page.

What the working parts say (the pipeline's stages, the work behind the reader, a failed request, a missing model, a
viewer that draws nothing) is a `taslation.messages.Message`: a stable dotted code (`pipeline.stage_reading`,
`ollama.unreachable`, ...) and its params (numbers and short strings, never text of the book), registered with
their English templates in `messages.py`. A window maps the code to its own catalog (`messages.render(message,
catalog)` does it, English where the catalog has no entry); `str(message)` is the English fallback, and since
`Message` is a `str`, code that knows nothing of codes shows it as the string it always got.

| `taslation/detect/tilt.py` | Lettering set at a slant. `lettering_tilt` measures how far a region's lettering is turned (`TextRegion.angle`, degrees counter-clockwise) from the glyph-sized pieces of the ink in its text box and mask: the ink is turned through ±45° (1° steps, then 0.25° round the best) and projected onto both axes, and the angle is where the product of the two projections' sharpness (the sum of the squared counts) peaks: the lines pile up across, the glyphs set in step along them. The axis the turning sharpens the most tells columns from rows. An angle of `DEAD_ZONE` (3°) or less, a confidence (`1 - upright / best`) under `MIN_CONFIDENCE`, fewer than `MIN_PIECES` glyph-sized pieces or lines shorter than `MIN_RUN` line widths count as upright: angle 0, and the region takes the straight path of before, byte for byte. A short word (too few pieces or too short lines for that search: two to four glyphs, a short column or row) is measured by `short_tilt` instead, as a text detector measures a line (the line quad of DBNet, PaddleOCR and the comic text detector): the minimum-area rectangle round its ink (its angle taken from the corners, never OpenCV's own angle, whose convention changed in 4.5.1), checked against the principal axis of the ink's second moments and the angle of the sharpest projection across the line. It is slanted only when all three agree within `SHORT_AGREE` (2°), the rectangle is `SHORT_ELONGATION` times as long as wide and `SHORT_GAIN` smaller than the upright box, the ink is one line, and the mean lies past the dead zone (`Tilt.short`). ## What is stored where

| Data | Where | Lifetime |
|---|---|---|
| Captured page images, crops, translated images | process memory | until the next page / exit |
| OCR results | process memory (`Pipeline._ocr_memo`) | until exit |
| Previous-page context for the translator | process memory | until exit |
| Translated text + normalised bubble boxes/outlines + page fingerprints, and for a bubble with a part set larger the part as offsets into its translation and a ratio (`large`; no Japanese) (protected, below) | `~/.taslation/cache/<book>[.<language>].json` | until you delete it |
| Short lines kept for reuse (`linememo`): per translator, model and language, a keyed hash of each line (HMAC-SHA-256 with the book's random secret, kept beside them) and its translation, a person's marked; never the Japanese (protected, below) | the book's cache file, its `lines` field | with the cache: deleted, exported, imported and renamed with it |
| Reader-marked rectangles (text here / nothing here) per page fingerprint (protected, below) | `~/.taslation/annotations/<book>.json` | until you delete it |
| Glossary: terms as in the book with the rendering to use (protected, below) | `~/.taslation/glossary/<series>[.<language>].json` | until you delete it |
| Frames of the pages turned past, held until the backlog has read them (PNG data, `pageimages.pack`), what it read of them (text and geometry) and the regions as read of the pages done; the pages lettered and the regions erased in this session (`render.memo`) | process memory, within the backlog's caps (`FRAME_CAP_MB` 256 for the frames, `UNIT_CAP` 1000 units read, `DONE_CAP_MB` 64) and the memo's budgets (`SHOWN_BUDGET` 96 MB, `ERASED_BUDGET` 64 MB) | a frame until its page is read; the backlog until another book or another viewer window (`drop_backlog`) or exit; the memo until another book (`Pipeline.forget_shown`) or exit |
| Translator's notes written by versions before 2026-11-06 (no longer read or written; protected at the start, below) | `~/.taslation/series/<series>[.<language>].json` | until you delete it |
| The window's language, the target language of the "To:" box, the name last given to a book per viewer, the books whose Series and Volume the reader split otherwise than the parser (`book_series`: the name and its series, the latest 500), whether the first start's popup is done with (`first_steps_done`); a viewer's window TASlation enlarged, while it is (its handle, process, class and rectangle before) | `~/.taslation/ui.json` | until you delete it (the enlarged window: until it is put back) |
| What was learned of the viewers on this computer (`viewerparts`): title segments that are a viewer's or a book's, the tab titles and program file names of the windows chosen as the viewer, the viewers whose one-segment titles named no book, the names of the books kept when this version first ran | `~/.taslation/viewers.json` (never exported, never in a cache or a log) | until you delete it (deleting it: the viewer is picked once more, and its name may show in the Book box until learned again) |
| Capture areas (margins) per viewer window title, and for a viewer that is no browser whether it draws while covered (what versions up to 1.0.1 kept there besides, page keys among it, is left and ignored) | `~/.taslation/profiles.json` | until you delete it |

Where two names give one file name ("Pebble:Harbor 1" and "Pebble Harbor 1"; "QUILLPOND 1" and "Quillpond 1" on Windows), the second
name's file has `<name>-<hash>` in place of `<name>` (`names.py`).

The files of `cache/`, `annotations/`, `glossary/` and `series/` (with the `.before-import`, `.before-apply`,
`.unreadable-<date>` and `.corrupt` copies and a save's leftover `*.tmp`) are protected at rest (`protect.py`):
`TASLATION-PROTECTED-1`, a newline, one line of plain ASCII that says what the file is (read to its end, not
compared), a newline, then the Windows DPAPI blob (user scope, TASlation's entropy) of the store's JSON in UTF-8
compressed with zlib. Only the Windows user who saved a file can open it, on the computer it was saved on; any
program running as that user can. A file that begins otherwise is an earlier version's plain JSON: read as it is,
protected at the next start or save. The window's own files (`ui.json`, `viewers.json`, `profiles.json`,
`notice.json`) are plain JSON as before: `ui.json` and `viewers.json` hold the names of books as their windows were
titled, and the installer reads `ui.json`. The export (above) is the only form of a cache that moves to another
computer or survives the loss of the Windows profile's key (an administrator's password reset, a new profile, a
reinstall).

There is deliberately no way to save a page or a translated page to disk.

Nor is there a way to read a page in TASlation without the viewer: reading is on the viewer only. The page area shows
the viewer's current frame and nothing else, with the cached translation laid over it while the page fingerprint
matches; no page is shown from memory. The captures of the pages turned past serve only their reading behind the reader,
and each goes once its page is read; nothing of them is shown.
The reason is the same as for the cache: a book paged through in TASlation away from its viewer would be read
outside the conditions it was sold under, which matters where what is paid depends on what is viewed; read in the
viewer, it is read under the same conditions as by a reader in Japan.
