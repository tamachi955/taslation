# インストールと動作環境

English: [INSTALL.md](INSTALL.md)

## 動作環境

* Windows 10/11（64 ビット）
* 空きディスク約 7.5 GB（ポルトガル語（ブラジル）とトルコ語に翻訳する場合は約 9.0 GB。翻訳モデルは PLaMo 3 Translate 2B が約 1.8 GB（取り込むあいだだけ約 3.8 GB）、ポルトガル語（ブラジル）とトルコ語に使う Qwen3.5 4B が約 3.3 GB で、入れるのは翻訳先に要るどちらか一方です）。
  NVIDIA の GPU があるパソコンでは、PyTorch の GPU 版の分がさらに約 3.7 GB（インストールのあいだだけ、もう約 2.6 GB）要ります
* RAM 16 GB 推奨（実測では、TASlation 本体が最大約 2.5 GB、翻訳を受け持つ Ollama が GPU ありで最大約 2 GB、GPU なしで最大約 4 GB を使いました。Ollama のキャッシュを切った状態（TASlation が起動する Ollama にはそう設定して渡します）の値です。キャッシュを切らないと、Ollama は GPU ありで最大約 10 GB、GPU なしで最大約 7.4 GB を使いました。TASlation を閉じると、TASlation が起動した Ollama も止まるので、その分の RAM は空きます。8 GB のパソコンでは試していません）
* NVIDIA GPU（メモリ 6 GB）推奨。実測では翻訳モデルが約 1.9 GB、絵の上の文字を消すモデルが約 0.5 GB を使い、ほかに Windows やほかのアプリが使う分があります。4 GB の GPU でも動きますが、GPU メモリの空きが約 3 GB より少ないと翻訳モデルの一部が CPU で動き、翻訳が約 1.5 倍遅くなります。GPU が無くても動きます（翻訳は約 4 倍遅くなります）。AMD と Intel の GPU は使いません（CPU で動きます）。
* 本を表示するビューア（アプリやブラウザ）

| 処理 | GPU あり | GPU なし |
|---|---|---|
| 1画面に1ページ（約10行） | 約6秒（3〜8秒） | 約23秒（12〜30秒） |
| 1画面に見開き2ページ（約16行） | 約9秒（6〜14秒） | 約30秒（19〜45秒） |
| 起動して最初のページ | 翻訳モデルは TASlation の起動中に読み込むので、読み込みが済んでいれば増えない（起動から約6秒で済む）。「起動時に翻訳モデルを読み込む」をオフにすると、さらに4〜5秒 | 同じ |
| 1冊（190ページ）をまるごと読んで翻訳する | 約15〜20分 | 約35分〜1時間 |

測定に使ったパソコンは、Intel Core i7-9700F（8コア）、RAM 48 GB、GeForce GTX 1660 Ti（6 GB）です。1920×1080 の画面に表示した見本の漫画のページで測りました。1冊の時間は見積もりで、GPU ありは 100 ページ、GPU なしは 16 ページを実際に測った結果から計算しています。ページをめくる時間は入っていません。行の多いページほど時間がかかります（1行の翻訳は GPU ありで約 0.4 秒、GPU なしで約 1.5〜1.8 秒）。ページの読み取り（OCR）は CPU で行うので、GPU があっても速さは変わりません（見開き1画面で約3秒）。

## インストール

1. GitHub の「Code」→「Download ZIP」でダウンロードし、ZIP を**すべて展開**します。インストール後はフォルダーを移動しないでください。
2. `install.cmd` をダブルクリックします。警告が出たら「詳細情報」→「実行」で続けてください。
3. 最初に翻訳先の言語を尋ねます（番号か英語の名前。Enter で表示された言語）。この言語で翻訳モデルが決まります。
   次に、3つの OCR モデル（合わせて約 700 MB）の利用条件（非営利のみ、CC BY-NC-SA 4.0）への同意を1回だけ尋ねます。TASlation はこれらのモデルなしではページを読めないので、
   同意しないときはインストールしません。翻訳先がポルトガル語（ブラジル）とトルコ語以外なら、翻訳モデル PLaMo 3 Translate 2B（約 1.8 GB）のライセンス（PLaMo Community License）への同意も尋ね、同意しないときはやはりインストールしません（この2つの言語は Qwen3.5 4B、約 3.3 GB で、ライセンスへの同意は要りません）。
   PLaMo のライセンス（2026年11月9日改定）の要点は、商用以外は無料で登録不要、18歳以上か保護者の同意、入力と翻訳結果に要る権利は自分で確保すること、翻訳を人に渡したり公開したりするときの表示です（`docs/THIRD_PARTY.md`。TASlation は翻訳を公表しないようお願いしています）。残りの質問は Enter で答えれば、このパソコンに必要なものがそろいます。
   Python、Ollama、翻訳モデルが無いときに、それを入れるかどうかの質問に「いいえ」と答えたときも、TASlation が動かないか翻訳できないので、何もインストールせずにその場で止めます。もう一度 `install.cmd` を実行すると、また尋ねます。
   Python と Ollama を入れるかどうかの質問に Y と答えると、それをインストールする winget（Windows のパッケージ管理ツール）が示す利用条件にも同意したことになります（途中で winget に尋ねられないように）。
   絵の上の文字を見つけて消す2つのモデル（レイアウトモデル約 170 MB、画像補完モデル LaMa 約 200 MB）を入れるかどうかも尋ねます。
   NVIDIA の GPU があるパソコンでは Enter で入れ（[Y/n]。TASlation は GPU で2つとも既定で使います）、
   GPU のないパソコンでは Enter で入れません（[y/N]。そのパソコンでは既定で使わないモデルです）。コンソールのない実行と `-Yes` では、どちらのパソコンでも入れません。
   質問は、Windows の表示言語が日本語なら日本語で、それ以外は英語で表示します。
4. スタートメニューの「TASlation」から起動します。

PyTorch（TASlation が OCR と LaMa に使う部品）は、NVIDIA の GPU があるパソコンには GPU 版（CUDA 版。ダウンロード約 2.6 GB、RTX 50 シリーズなど最新の GPU では約 2.0 GB）、
ないパソコンには CPU 版（約 0.13 GB）を入れます。GPU があるかどうかは、NVIDIA のドライバーに付いている `nvidia-smi` に尋ねるだけで（ネットワークは使いません）、質問はしません。
ダウンロードの大きさは、質問のあいだ、ダウンロードを始める前に表示します。GPU 版には NVIDIA のドライバー 528.33 以降（RTX 50 シリーズなどは 580 以降）が要り、
それより古いドライバーではそう表示して CPU 版を入れます（ドライバーを更新して install.cmd を実行し直せば GPU 版になります）。GPU 版はインストールのあと GPU で一度計算して確かめ、
GPU で動かなかったときは、1行でそう伝えて CPU 版を入れ、インストールを続けます。GPU 版が3回試してもダウンロードできなかったときは、ほかのダウンロードと同じくインストールを止めます
（CPU 版が入っていれば、そのまま残ります）。AMD と Intel の GPU は GPU として数えません。
すでに入っている GPU 版はそのまま残します。この版より前に CPU 版を入れたパソコンでは、install.cmd を実行し直すと GPU 版に置き換えます（`update.cmd` では置き換えません）。

Ollama は、TASlation が使うあいだだけ動かします。自分で起動した Ollama は、そのまま動かしておきます。

* インストーラーが Ollama を入れたときは、Windows と一緒に起動しないようにし、インストールのあと Ollama を動かしたままにしません。
  Ollama のアプリは最初に起動したとき、Windows と一緒に起動するように自分を登録しますが、インストーラーはその登録を消し、このフォルダーの `.ollama-by-install` にそう書き残します。
  TASlation は翻訳するときに Ollama を起動し、終わるときに止めます。Ollama を自分で使うときは、スタートメニューから起動してください。
* 前からある Ollama は、動いているかどうかも含めてそのままにします。Windows と一緒に起動するようになっているときは、それをやめるかどうかを1回だけ尋ねます
  （既定は「いいえ」。`-Yes` では答えません）。「はい」なら消した登録を `.ollama-autostart-by-install` に書き残し、`uninstall.cmd` が元に戻します。
  いま動いている Ollama は、終了するかサインアウトするまで動き続けます。
* 翻訳モデルを Ollama に入れるとき、Ollama が動いていなければ、インストーラーは `ollama serve` を非表示のウィンドウで起動し（Ollama のアプリは起動しません）、
  最後の確認の前に止めます。

Ollama の設定は2つあります。TASlation が起動する Ollama には、TASlation がこの2つを渡すので、インストーラーはこの Windows ユーザーには何も設定しません。
前からある Ollama には、インストーラーが質問せずにこの2つを設定します。どちらも、その環境変数がこの Windows ユーザーにもインストールを実行しているウィンドウにもまだ設定されていないときだけで、
設定したあと Ollama を1回再起動します。すでに値があれば、そのままにします。再起動したサーバーが応答したときだけ「ok」と表示し、応答しないときは警告して、
スタートメニューから Ollama を起動するかパソコンを再起動するよう伝えます（設定は保存済みで、次に起動したときから効きます）。

* 環境変数 `LLAMA_ARG_CACHE_RAM=0`。これがないと Ollama は、以前の要求のキャッシュに
  RAM を最大 8 GB 使います。TASlation の測定では、このキャッシュで翻訳が速くなったのは GPU がないときだけで、約 8 % でした
  （そのかわり Ollama の RAM は約 3.3 GB 多くなりました）。インストーラーがこのユーザーに設定したときは、このユーザーが動かす Ollama と、
  このユーザーのほかのプログラムのうち llama.cpp の `LLAMA_ARG_*` 環境変数を読むものに効きます。
* NVIDIA の GPU のメモリが 6 GB 以下なら、`OLLAMA_KV_CACHE_TYPE=q8_0` も設定します。Ollama が GPU のメモリを節約し、翻訳モデルが GPU に収まりやすくなります。

インストーラーが設定した値は、そのままなら `uninstall.cmd` が消します。手で元に戻すには、スタートメニューで「環境変数」を検索して
「アカウントの環境変数を編集」を開き、その変数を削除してから Ollama を再起動します。

TASlation が起動する Ollama には、ウィンドウ全体のキャッシュも渡します。`LLAMA_ARG_SWA_FULL=1` と、`0` の代わりに `LLAMA_ARG_CACHE_RAM=256` です
（「ツール > 設定...」の「システム」の「翻訳モデルのウィンドウキャッシュ」、`taslation.toml` の `ollama_window_cache`）。上と同じく、すでに設定されている変数
（TASlation の環境にあるもの、または Windows がこのユーザーかこのパソコンに保存しているもの）は、その値のまま渡します。
これで llama.cpp は翻訳モデルのウィンドウ全体のキャッシュを持ち、要求ごとにプロンプト全体を計算し直さずに前の要求の続きから計算し、
以前の要求 256 MB 分を RAM に置きます。既定（「OCR が GPU に残るなら使う」）では、TASlation が Ollama を起動するたびに決めます。
増える GPU のメモリーのために OCR の読み手のうち2つが GPU から CPU に移ることになるときは、ウィンドウキャッシュを使いません
（6 GB の GPU で、ほかのプログラムがそのうち約 1.3〜1.4 GB を使っているときだけです）。「使わない」はいつも使わず、「常に使う」はいつも使います。
TASlation が起動した Ollama がこれを使っているかどうかは、ウィンドウと `taslation doctor` の翻訳の行に出ます。

自分で動かす Ollama には、インストーラーも TASlation もこの2つの変数を設定しません。そこでウィンドウキャッシュを使うには、
上と同じようにアカウントに `LLAMA_ARG_SWA_FULL=1` と `LLAMA_ARG_CACHE_RAM=256` を設定して Ollama を再起動します。その Ollama が動かすすべてのモデルに効きます。
TASlation の翻訳モデルで測った結果です（PLaMo 3 Translate 2B、OpenMantra データセットの 214 ページ、Ollama 0.40.16、6 GB の NVIDIA GPU。
docs/OFFLINE_VERIFICATION.md の「The full-size window cache」）。

| | なし（`LLAMA_ARG_CACHE_RAM=0`） | あり（`LLAMA_ARG_SWA_FULL=1`、`LLAMA_ARG_CACHE_RAM=256`） |
|---|---|---|
| 一冊通しの翻訳 | 401 秒 | 296 秒 |
| 1ページずつの翻訳 | 412 秒 | 299 秒 |
| GPU なし、1行あたり | 1.28 秒 | 0.98 秒 |
| 読み込んだモデルの GPU メモリー、`OLLAMA_KV_CACHE_TYPE=q8_0` | 1,933 MB | 2,065 MB |
| 読み込んだモデルの GPU メモリー、Ollama 既定の KV キャッシュ（f16） | 2,009 MB | 2,229 MB |
| モデルのサーバーの RAM の最大（一冊通し） | 2.0 GB | 0.9 GB |

翻訳の採点は変わりませんでした（一冊通しで chrF 41.18 と 40.99。差は1回ごとのばらつきの範囲です）。
ウィンドウを区切る層があり文脈の長いモデルでは、ウィンドウ全体のキャッシュがここよりずっと多くの GPU メモリーを使うことがあります。

ダウンロードに失敗したときは、15 秒おいてもう一度試し、全部で3回試します（何が失敗したか、何回目か、何秒待つかを表示します）。
3回とも失敗したときは、インストールを止めます。配布元のサーバーがダウンロードを拒否したか、ファイルをもう置いていないとき
（HTTP 401、403、404、410）は、試し直しても変わらないので、すぐに止めて、TASlation を更新する（最新版をダウンロードして `update.cmd` を実行する）か、
プロジェクトの Issues ページを見るよう表示します。止まったときのことは、下の「インストールが止まったとき」にあります。

最後まで進んだのに TASlation がまだ翻訳できないとき（最後の確認で足りないものが見つかったときや、winget がなく Ollama をインストールできなかったとき）は、
最後の行にそう表示し、どうすればよいかを伝えます。警告があれば、その前にまとめて表示します。

ネットワークを使うのはインストールのときだけです。Python、Ollama、翻訳モデルは、無ければ同意を得てダウンロードします。
その後の TASlation は、このコンピューターの外には接続しません。

質問は最初にまとめて行います。答えたあとは席を離れてかまいません。回線にもよりますが、15〜60 分ほどかかります。
ダウンロードの進み具合はパーセントと MB で表示します。接続が途中で切れても、切れたところから続けます。

誰も見ていない実行のための `install.cmd -Yes` は、それだけではライセンスに同意しません。前もって同意できるのはインストールの自動チェックのときだけで、2つのライセンスを読んだ人が `TASLATION_AGREE_OCR_LICENCE` と `TASLATION_AGREE_PLAMO_LICENCE` に install.ps1 のヘルプにある文をそのまま設定し、設定することがその人の同意になります（自分で入れるときは、質問に答えてください）。
同意のない `-Yes` の実行も、何もインストールせずに止まります。失敗したダウンロードも、同じように3回試します。

### インストールが止まったとき

インストールが止まったときは、最後の数行に、TASlation がまだインストールされていないこと（前にインストールしたフォルダーでは、インストールが最後まで終わらなかったこと）と、
何があったかを表示します。止まったインストールは、スタートメニューのショートカットを作りません。終了コードは 0 以外です。

* 質問に「いいえ」と答えて止まったとき（終了コード 3）: 何もインストールしていません。もう一度 `install.cmd` を実行すると、また尋ねます。
* ダウンロードかインストールが3回とも失敗して止まったとき（終了コード 1）: ネットワークとディスクの空きを確かめて、もう一度 `install.cmd` を実行してください。
  ここまでにインストールしたものとダウンロードしたものはすべて残っていて、その続きから進めます。OCR モデル、ページ用モデル、フォント、PLaMo のファイルは、
  途中までダウンロードした分から続けます。
* 配布元のサーバーがダウンロードを拒否したか、ファイルをもう置いていないとき（終了コード 5）: もう一度実行しても変わりません。
  TASlation を更新するか、プロジェクトの Issues ページを見てください。
* そのほかの理由で止まったとき（終了コード 1）: `error:` の行に、何があったかと、どうすればよいかを表示します。

前にインストールしたフォルダーで止まったときは、スタートメニューのショートカットを、TASlation が今のままで起動するときだけ残します（そう表示します）。
起動しないときはショートカットを消し、インストールが最後まで終わったときにまた作ります。

## 更新

1. 新しい ZIP をダウンロードし（GitHub の「Code」→「Download ZIP」）、TASlation を閉じます。
2. TASlation のフォルダーにある `update.cmd` をダブルクリックします。
3. 新しい ZIP の場所を尋ねられたら、ZIP ファイル（または展開したフォルダー）をウィンドウにドラッグして Enter を押します。
   「ダウンロード」フォルダーにある、いちばん新しい `taslation*.zip` なら、Enter だけで選べます。
4. 今のバージョンと新しいバージョン（日付つき）を表示して、1回だけ確認します。そのあと新しいファイルをコピーし、`install.cmd` と同じインストールを続けます
   （新しい版に要るものがあれば、ダウンロードの前に尋ねます）。

このインストールが止まったときは、新しい版のファイルはすでに古い版のファイルに上書きしてあり、古い版は残っていません（最後の数行にそう表示します）。
スタートメニューのショートカットは、TASlation が今のままで起動するときだけ残ります。同じ ZIP でもう一度 `update.cmd` を実行すると、その続きから進めます
（質問に「いいえ」と答えて止まったときは、また尋ねます）。

更新のあとのインストールでは、入っている PyTorch をそのまま使います。NVIDIA の GPU があるのに CPU 版が入っているときは（この版より前に入れた場合）、
約 2.6 GB のダウンロードを尋ねずに始めることはせず、そう表示します。GPU 版にするには `install.cmd` を実行してください。
上の Ollama の設定は、更新のあとのインストールでも行います（前からある Ollama には、この版より前にインストールしたパソコンでも `LLAMA_ARG_CACHE_RAM` が設定されます）。

`taslation.toml`、`.venv`、`models`、データフォルダー（`~/.taslation`）はそのまま残ります。プログラムのフォルダー `taslation\` は新しい版と同じ中身になり
（新しい版にないファイルは消えます）、それ以外のファイルは消しません。`update.cmd` 自体はネットワークを使わず、渡された ZIP かフォルダーだけを読みます。
今のバージョンと日付は、ヘルプ →「TASlation について」でも確かめられます。

手でコピーする場合は、TASlation を閉じてから、ZIP の中の `taslation-main` フォルダーの**中身**を `install.cmd` があるフォルダーへコピーし
（フォルダーごとコピーしないでください。確認が出たら「置き換える」）、`install.cmd` を実行します。

## アンインストール

`uninstall.cmd` をダブルクリックすると、消えるものの一覧を表示して確認します（既定は「いいえ」）。翻訳キャッシュなどのデータを消すかどうかも、その場で尋ねます（既定は残す）。
インストーラーが設定した Ollama の環境変数（`LLAMA_ARG_CACHE_RAM`、`OLLAMA_KV_CACHE_TYPE`）は、その値のままなら消します。自分で設定し直した値は残します。動いている Ollama は、再起動するまで前の設定のままです。
TASlation が起動して動いたままになっている Ollama は止めます（ほかのプログラムがモデルを読み込んでいるときは止めません）。Ollama のモデルを消すとき、Ollama が動いていなければ、`ollama serve` を非表示のウィンドウで起動し、終わったら止めます。
Ollama を残すとき、インストールのときに「はい」と答えて Windows と一緒に起動しないようにした Ollama は、元どおり Windows と一緒に起動するようにします。
TASlation のために入れた Ollama は、Windows と一緒に起動しないままにして、そうしたいときの方法を表示します。最後にフォルダーを削除してください。
